# 絵の細かさの見本(`mocks/resolution.html`)の元

体の形とポーズを決めて、好きな細かさのドット絵に描き出します(Python。Pillowとnumpyが要る)。

| ファイル | 中身 |
|---|---|
| `rig.py` | 部品(棒、だ円、多角形)を重ねて、4段の陰と、黒くないふちを付ける道具 |
| `hero.py` | ヒーローの頭と顔の部品(6頭身で試した版もここ) |
| `hero2.py` | ヒーローの待機とパンチ(いまと同じ等身。見本で使っている版) |
| `civ.py`、`civ2.py` | 市民(パーカーの男)。`civ2.py`がいまと同じ等身の版 |
| `bg.py` | 路地裏の背景。画面の横のドット数を渡す |
| `scene.py` | 背景に人物を置いた画面を作る。`sc_now.png`は、いまのゲームの画面を216×214にもどしたもの |
| `build.py`、`page.html` | 絵をページに入れて`mocks/resolution.html`を作る |

作り直すときは、`python3 scene.py`のあと`python3 build.py`を動かします。

# Stupid Hero

敵と味方の区別がつかないヒーローに、プレイヤーが「こいつはワル、こいつは市民」と教えて、街を悪党とヒーローの両方から守るゲームです。スマホのブラウザで、縦持ちで遊びます。

遊ぶ:https://mayonaka-ratori.github.io/StupidHero/

## 遊び方

1. 人が1人ずつ出てくるので、左にスワイプでワル、右にスワイプで市民に分ける(下のボタンでもよい)。見た目、動き、プロフィール、オペレーターの一言、「持ち物」の窓が手がかり
2. 分け終わると、ヒーローが分けた通りに動く。ワルにした人は殴り、市民にした人には手を振って素通りする
3. 殴る前に「待て!」で止める、逃げるワルに「行け!」で追い打ちする(使い方は初めて出てきたときに教えてくれる)
4. 波ごとに答え合わせがある。だれがワルだったか、何で見分けられたかが分かる
5. 波を3回こなすとボス戦。「行け!」を連打して倒す
6. 最後に称号が出る。集めた称号は一覧で見られる。結果はSNSに共有できる

初めて遊ぶ人は、タイトルでタップするとすぐ路地裏が始まります。ステージ前の掛け合いは、そのステージで一度だけ出ます。

中断のボタンで開くメニューから、「光と揺れを弱くする」「ゆっくりモード」(仕分けの時間が1.5倍。称号は同じ)、音を切りかえられます。

ステージは3つあります。

| ステージ | 悪党 | 開き方 |
|---|---|---|
| 1 路地裏 | チンピラ | 最初から遊べる |
| 2 地下駐車場 | ギャング | 路地裏のボスを一度倒すと開く |
| 3 ショッピングモール | 宇宙人 | 地下駐車場のボスを一度倒すと開く |

## 手元で動かす

Node.js 22を使います(CIと同じ)。

```sh
npm ci
npm run dev        # 開発用のサーバー。表示されたURLをスマホかブラウザで開く
```

よく使うコマンド:

| コマンド | すること |
|---|---|
| `npm run dev` | 開発用のサーバーを立てる(同じネットワークのスマホからも開ける) |
| `npm test` | テスト(vitest)を動かす |
| `npm run typecheck` | 型を確かめる(tsc) |
| `npm run build` | 型を確かめてから`dist/`に組み立てる |
| `npm run preview` | 組み立てたものを手元で開く |
| `npm run build:page` | フォントを同梱しない版を`dist-page/`に組み立てる(Google Fontsから字を読むページに載せるとき) |

## 作り

- TypeScriptとPhaser 3。組み立てはVite
- 絵は、いまは全部コードで描いている。PNGを置けば差し替わる(`docs/DEVELOP.md`の「絵を差し替える」)
- 音はWeb Audioでその場で作る(メガドライブ風のFM音源とPSG)
- 記録と設定はそのスマホの中(localStorage)だけに残す
- 公開はGitHub Pages。手で動かしたときだけ公開する

# Stupid Hero

敵と味方の区別がつかないヒーローに、プレイヤーが「こいつはワル、こいつは市民」と教えて、街を悪党とヒーローの両方から守るゲームです。スマホのブラウザで、縦持ちで遊びます。

遊ぶ:https://mayonaka-ratori.github.io/StupidHero/

## 遊び方

1. 人が1人ずつ出てくるので、左にスワイプでワル、右にスワイプで市民に分ける(下のボタンでもよい)。見た目、動き、プロフィール、オペレーターの一言、「持ち物」の窓が手がかり。地下駐車場では前の人とおそろいの小物、ショッピングモールでは少し待つと分かる動きのくずれも手がかりになる
2. 分け終わると、ヒーローが分けた通りに動く。ワルにした人は殴り、市民にした人には手を振って素通りする
3. 殴る前に「待て!」で止める、見逃したワルに「行け!」で追い打ちする(使い方は初めて出てきたときに教えてくれる)。地下駐車場では仲間を呼んで車で逃げるギャングを、ショッピングモールでは買い物客を連れ去るUFOを、「行け!」で止める
4. 波ごとに答え合わせがある。だれがワルだったか、何で見分けられたかが分かる
5. ショッピングモールでは、2回目の波の結果発表のあとにタイムセールラッシュがある。押し寄せる人にヒーローが次々と殴りかかるので、市民にだけ「待て!」を押す
6. 3回目の波の最後はボス戦。「行け!」を連打して倒す
7. 最後に称号が出る(全部のステージで17個)。集めた称号は一覧で見られる。結果はSNSに共有できる

初めて遊ぶ人は、タイトルでタップするとすぐ路地裏が始まります。2回目からは、タイトルのあとにステージを選ぶ画面が出ます。ステージ前の掛け合いは、そのステージで一度だけ出ます。

中断のボタンで開くメニューから、「光と揺れを弱くする」「ゆっくりモード」(仕分けの時間が1.5倍。称号は同じ)、音を切りかえられます。

## ステージ

ステージは3つあります。

| ステージ | 悪党 | 見分け方 | 開き方 |
|---|---|---|---|
| 1 路地裏 | チンピラ | 1人をよく見る(ポケットの中身、袋の中身など) | 最初から遊べる |
| 2 地下駐車場 | ギャング | 前の人と比べる(おそろいの色の小物、仲間の合図) | 路地裏のボスを一度倒すと開く |
| 3 ショッピングモール | 宇宙人 | 少し待って動きを見る(ときどき動きがくずれる)。ただし全員を待つ時間はない | 地下駐車場のボスを一度倒すと開く |

## 手元で動かす

Node.js 22.12以上を使います(CIは22)。

```sh
npm ci
npm run dev        # 開発用のサーバー。表示されたURLをスマホかブラウザで開く
```

よく使うコマンド:

| コマンド | すること |
|---|---|
| `npm run dev` | 開発用のサーバーを立てる(同じネットワークのスマホからも開ける) |
| `npm test` | テスト(vitest)を動かす |
| `npm run typecheck` | 型を確かめる(tsc) |
| `npm run build` | 型を確かめてから`dist/`に組み立てる |
| `npm run preview` | 組み立てたものを手元で開く |
| `npm run build:page` | フォントを同梱しない版を`dist-page/`に組み立てる(Google Fontsから字を読むページに載せるとき) |

## 作り

- TypeScriptとPhaser 3。組み立てはVite
- 絵は、いまは全部コードで描いている。PNGを`public/art/`に置いて`public/art/manifest.json`に書けば差し替わる(`docs/DEVELOP.md`の「絵を差し替える」)
- 煙、火の粉、UFOの光の粒も、コードで点を打って描いている。こちらはPNGでは差し替えない(`docs/DEVELOP.md`の「煙と光の粒を足す、変える」)
- 音はWeb Audioでその場で作る(メガドライブ風のFM音源とPSG)
- 記録と設定はそのスマホの中(localStorage)だけに残す
- pushすると、GitHub Actionsで型の確かめとテストが動く
- 公開はGitHub Pages。手で動かしたときだけ公開する(`docs/DEVELOP.md`の「公開する」)

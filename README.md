# Stupid Hero

敵と味方の見分けがつかないヒーローに、「この人はワル」「この人は市民」と教えてあげるゲームです。悪党だけでなく、勘違いしたヒーローからも街を守ります。スマホのブラウザを縦に持って遊びます。

遊ぶ:https://mayonaka-ratori.github.io/StupidHero/

## 遊び方

1. 人が1人ずつ出てくるので、ワルなら左、市民なら右へスワイプします(下のボタンでも分けられます)。見た目、しぐさ、プロフィール、オペレーターの一言、「持ち物」の窓がヒントです。地下駐車場では前の人とおそろいの小物、ショッピングモールでは少し待つと見える動きのくずれ、高層ビルでは照明や机の小物(「まわり」の窓)もヒントになります
2. 分け終わると、ヒーローがその通りに動きます。ワルと決めた人は殴り、市民と決めた人には手を振って通り過ぎます
3. 殴りかかる前なら「待て!」で止められます。見逃したワルには「行け!」で追いかけさせます(どちらも、初めて出てきたときに使い方の説明があります)。地下駐車場では仲間を呼んで車で逃げるギャングを、ショッピングモールでは買い物客をさらうUFOを、「行け!」で止めます。高層ビルでは念力で運ばれる物を「行け!」で落とします。ソファの上で落とせば何も壊れません
4. 波が終わるたびに答え合わせがあります。だれがワルだったのか、どこを見れば見分けられたのかが分かります
5. ショッピングモールでは、2回目の波の結果発表のあとにタイムセールラッシュが始まります。押し寄せる人にヒーローが片っぱしから殴りかかるので、市民のときだけ「待て!」を押します。高層ビルでは3回目の波のあとにエレベーターラッシュがあり、乗ってくる人のうち市民にだけ「待て!」を押します
6. 最後の波(高層ビルは4回目、ほかは3回目)の締めはボス戦です。「行け!」を連打して倒します
7. 最後に称号がもらえます。称号は全部のステージとフリープレイを合わせて24個あり、集めたものは一覧で見られます。結果はSNSに共有できます

初めて遊ぶときは、タイトルをタップするとすぐに路地裏が始まります。2回目からは、タイトルのあとにステージを選ぶ画面が出ます。ステージの前の掛け合いが出るのは、そのステージで最初の1回だけです。

一時停止のボタンから開くメニューでは、「光と揺れを弱くする」「ゆっくりモード」、音のオンとオフを切りかえられます。ゆっくりモードにすると、仕分けの時間が1.5倍になります(フリープレイでは人と人の間とマークの長さが1.5倍)。もらえる称号は変わりません。

## ステージ

ステージは4つで、最後の高層ビルだけ波が4つあります。

| ステージ | 悪党 | 見分け方 | 遊べるようになる条件 |
|---|---|---|---|
| 1 路地裏 | チンピラ | 1人をじっくり見る(ポケットや袋の中身など) | 最初から遊べる |
| 2 地下駐車場 | ギャング | 前の人と見比べる(おそろいの色の小物、仲間への合図) | 路地裏のボスを一度倒す |
| 3 ショッピングモール | 宇宙人 | 少し待って動きを見る(ときどき動きがくずれる)。ただし全員を待っている時間はない | 地下駐車場のボスを一度倒す |
| 4 高層ビル | 超能力のヴィラン | まわりを見る(照明が紫になる、机の小物が浮く)。手品の糸や切れかけの蛍光灯のせいのこともある | ショッピングモールのボスを一度倒す |

## フリープレイ

仕分けをしないモードです。路地裏のボスを一度倒すと、ステージを選ぶ画面の「フリープレイ▶」から遊べます。

- 波の始めに、ヒーローが見た目だけでルールを決めつけます(「みんなワル」「みんないいひと」「ふうせん=ワル」など)。ルールは左上の札に出ます
- ヒーローはそのルールの通りに殴りかかったり通り過ぎたりします。プレイヤーは、市民に「待て!」、悪さを始めたワルに「行け!」を押して、まちがいを直します
- 波は3回で、ボスは出ません。記録はクリアまでの時間です。逃がしたワルと、けがをした市民1人ごとに3秒が足されます
- 出てくる人と背景は、遊べるようになったステージのものがまざります

くわしくは[docs/FREEPLAY.md](docs/FREEPLAY.md)にあります。

## 手元で動かす

Node.js 22.12以上が必要です(GitHub Actionsでは22を使っています)。

```sh
npm ci
npm run dev        # 開発用のサーバーを起動する。表示されたURLをスマホかブラウザで開く
```

よく使うコマンド:

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発用のサーバーを起動する(同じネットワークのスマホからも開ける) |
| `npm test` | テスト(vitest)を実行する |
| `npm run typecheck` | 型を確かめる(tsc) |
| `npm run build` | 型を確かめてから、公開用のファイルを`dist/`に作る |
| `npm run preview` | `dist/`に作ったものを手元で開く |
| `npm run build:page` | フォントを入れない版を`dist-page/`に作る(字をGoogle Fontsから読むページに載せるとき) |

## 使っている技術

- TypeScriptとPhaser 3で作り、Viteで公開用のファイルにまとめています
- 絵は、いまは全部コードで描いています。PNGを`public/art/`に置いて`public/art/manifest.json`に書けば、その絵に差し替わります(`docs/DEVELOP.md`の「絵を差し替える」)
- 煙、火の粉、UFOの光の粒も、コードで点を打って描いています。こちらはPNGに差し替えられません(`docs/DEVELOP.md`の「煙と光の粒を足す、変える」)
- 音はWeb Audioでその場で鳴らしています(メガドライブ風のFM音源とPSG)
- 記録と設定は、遊んでいるスマホの中(localStorage)にだけ残ります
- pushすると、GitHub Actionsで型の確かめとテストが実行されます
- 公開先はGitHub Pagesです。手で公開の操作をしたときだけ公開されます(`docs/DEVELOP.md`の「公開する」)

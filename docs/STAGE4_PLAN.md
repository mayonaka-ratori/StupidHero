# ステージ4 高層ビル(超能力のヴィラン)の案

仕様を決める前の案です。はじめに雨の駅前、テレビ局、浮かんだ街の3つを出し、話し合って高層ビルにしました。雨の駅前の案から「周りを見る」見分け方を持ってきています。決まったら、この案をもとに`docs/STAGE4.md`を書き、このファイルは消します。

## あらすじ

超能力のヴィランの親玉が、店とオフィスが入った高層ビルの最上階でパーティを開いている。ヒーローは1階から入り、階を上がりながらヴィランを見分けていく。最上階のパーティ会場で親玉と戦う。

## 決めたいこと

| 項目 | 案 |
|---|---|
| 舞台 | 店とオフィスが入った夜の高層ビル。波ごとに階が変わる |
| 悪党 | 超能力のヴィラン。見た目は普通の人 |
| 見分け方 | 周りを見る。ヴィランの近くでは小物が浮き、明かりや画面がちらつく |
| 結果発表で足す遊び | 見逃したヴィランが念力で物を浮かせて市民に投げる。浮いている間に行けで止める |
| 途中のイベント | 波3のあと、最上階へ上がるエレベーターラッシュ |
| ボス | ビルのオーナー(実は親玉)。ボス戦の途中でシャンデリアを浮かせる |
| 開き方 | ショッピングモールのボスを一度倒すと開く |

## 波と階

波ごとに階が変わり、背景も変わる。ステージ1〜3は1つのステージで背景が1つだったので、ここは新しい。

| 波 | 階 | 人数 | 制限時間 | 背景 | 壊れる物 |
|---|---|---|---|---|---|
| 1 | 1階 ロビーとお店 | 5人 | 30秒 | 受付、自動ドア、カフェ、花屋、吹き抜け | 観葉植物、カフェの看板、花のかざり |
| 2 | 18階 オフィス | 6人 | 28秒 | 机、パソコンの画面、コピー機、ホワイトボード、窓の外に街の明かり | コピー機、観葉植物、給水機 |
| 3 | 35階 レストラン街 | 7人 | 30秒 | のれん、ショーケースの食品サンプル、水槽、窓の外に遠くの夜景 | 水槽、食品サンプル、ワインの棚 |
| 4 | 最上階 パーティ会場 | 7人と親玉 | 32秒 | シャンデリア、シャンパンタワー、ピアノ、大きな窓と月 | シャンパンタワー、氷の彫刻、ピアノ |

- 1つの波のヴィランは2〜3人(波4は3人と親玉)
- 階が上がるほど窓の外の街が小さく遠くなり、上がっていることが見て分かる
- 波と波の間は、階の数字が上がっていく短い場面(1秒くらい)でつなぐ。エレベーターの中は見せない(ラッシュのときに初めて中を見せたいので)
- 最上階の壊れる物は高いものにする(シャンパンタワー、ピアノ)。最後のステージなので、被害額が大きくなって笑えるようにする
- 時間の数字は遊んで直す

## 見分け方:周りを見る

ステージ1〜3の見分け方の続きとして、本人ではなく周りを見る。

| ステージ | 見分け方 |
|---|---|
| 1 路地裏 | 1人をよく見る |
| 2 地下駐車場 | 前の人と比べる |
| 3 ショッピングモール | 少し待って動きを見る |
| 4 高層ビル | 周りを見る |

ヴィランの能力のもれ:

- 近くの小物が少し浮く(ペン、名刺、コーヒーカップ、グラス)
- 近くの明かりや画面がちらつく(静電気)
- 髪の毛の先が少し逆立つ

紛らわしい市民:

- 静電気がたまりやすいセーターの人(髪が逆立つ)
- 切れかけの蛍光灯の下に立っている人(明かりがちらつく)
- 手品をする人(本当に小物を浮かせる。よく見ると糸がある)
- 風船を持った子ども(浮いている物がある)

### 絵の手間を減らす工夫

もれは人の絵ではなく、人の周りにコードで重ねて出す。そうすると、市民とヴィランを同じ絵にできる。ステージ2は小物の色、ステージ3はくずれのコマを人の絵に描いたが、ステージ4はそれが要らない。そのぶん見た目の種類を増やせる。

## 出てくる人(8種類)

階ごとに2種類ずつ足す。上の階には、下の階の人も上がってくる(波4には全部の階の人がまざる)。

| 階 | 見た目 | 市民にもある紛らわしさ |
|---|---|---|
| 1階 | 花屋の店員 | 花びらが舞っている |
| 1階 | 配達員 | 台車の上の荷物がゆれる |
| 18階 | 新人の会社員 | セーターで髪が逆立つ |
| 18階 | 清掃員 | モップの柄が立てかけてあって浮いて見える |
| 35階 | シェフ | 湯気が上がる |
| 35階 | ウェイター | お盆のグラスがゆれる |
| 最上階 | ドレスの女性 | 羽の飾りがふわふわ動く |
| 最上階 | 手品師 | 本当に小物を浮かせる |

- 親玉の化けた姿は、最上階の2種類と、ほかの階から1種類の中から選ぶ
- 波1には、もれがはっきり分かるヴィランを1人入れる(練習)

## 結果発表で足す遊び:念力で投げる

- 見逃したヴィランは、ヒーローが素通りしたあと、近くの物(観葉植物、コピー機、水槽、シャンパンタワーなど)を念力で浮かせる
- 浮いた物は、通りがかりの市民の上へゆっくり動く。この間に行けのマークが出る
- 行けを押すと、ヒーローがヴィランを殴り、物はその場に落ちて壊れる(被害額が増える)
- 押さないと物が市民に当たり、市民のけがになる。ヴィランは「逃がした」に数える
- ステージ3のUFOと同じく「押すと被害額が増える、押さないとけが人が出る」の迷いを作る。違いは、浮いた物ごとに被害額が違うこと(花のかざりなら安い、ピアノなら高い)

## 途中のイベント:エレベーターラッシュ

波3の結果発表のあと、答え合わせの前に1回だけ起きる。最上階へ上がるエレベーターの中で、乗ってくる人をヒーローがその場で殴ろうとする。市民にだけ待てを押す。ステージ3のタイムセールラッシュの変化版。

### 場面

- 外が見えるガラス張りのエレベーター。後ろの窓の外を、夜景が下へ流れていく
- 上に階の数字(35→50)。数字が上がるたびに少しずつ夜景が遠くなる
- ヒーローはエレベーターの奥に立ち、扉の方を向いて構える
- 画面は動かない(横に流れない)。ここだけ、いつもの通りとは違う見た目になる

### 遊び方

- 途中の階で扉が「チン」と開き、1人か2人が乗ってくる。扉が開くのは5回くらい、乗ってくるのは全部で8人くらい
- 乗ってきた人に待てのマークが出る。約1秒たつとヒーローが殴り、殴られた人は扉の外へ飛んでいく
- 2人乗ってきたときは、扉に近い人から1人ずつマークが出る
- 待てを押すとヒーローが止まり、その人はエレベーターの奥へ入って立つ

### タイムセールラッシュとの違い

| | タイムセールラッシュ | エレベーターラッシュ |
|---|---|---|
| 場所 | モールの通り(横に広い) | エレベーターの中(せまい、画面が動かない) |
| 人の来かた | 右から1人ずつ走ってくる | 扉が開くたびに1〜2人まとめて乗ってくる |
| 見分け方 | 宇宙人のくずれ(本人が変わる) | エレベーターの明かりがちらつく、階の数字が乱れる、箱がゆれる(周りが変わる) |
| 待てで通した人 | 左へ走って去る | エレベーターの奥にたまっていく |
| 終わり方 | 最後の人のあとにオペレーターの一言 | 最上階で扉が開く。待てで通した人が多いと、途中で「定員オーバー」のブザーが鳴るおまけ |

- 待てで通した人がエレベーターの中に残るので、たまっていく様子で「何人守れたか」が見える
- 待てで通したヴィランが中にいると、明かりがちらつき続ける。見逃したことがその場で分かり、少し気まずい
- 技は1つ(光のパンチ)、巻きぞえなし、物は壊れない、ラッシュの数はほかの数字に入れない。ここはタイムセールラッシュと同じ

### 始まり方

- 波3の最後の人のあと、ヒーローがエレベーターに乗りこむ。「WAVE3 CLEAR!」の帯
- 扉が閉まり、画面がエレベーターの中に切りかわる。「最上階へ!」の帯を出して、いったん止める
- オペレーターのカットイン:「乗ってくる人、全員殴っちゃう!」「明かりがちらついたらヴィラン!市民にだけ待て!」
- タップで始まる(タイムセールラッシュと同じ決まり)

## ボス:ビルのオーナー

- パーティの主催者。波4に化けた姿で紛れている
- 正体を現すと、会場のグラスや料理がいっせいに浮く
- ボス戦の途中で、シャンデリアを念力で浮かせて落とそうとする。行けの連打で止める。止められないと落ちて被害額が大きく増える
- 倒すと、大きな窓の外に朝日が出る(最後のステージの終わり)

## この案の妥当性

### よいところ

- 1階から最上階へ上がっていくので、どこまで進んだかが見て分かる。最上階に親玉がいるのも分かりやすい
- 店とオフィスが入ったビルは実際にあるので、階ごとに違う人と背景を出す理由になる。人を増やしたい、という望みに合う
- 「周りを見る」は、ステージ1〜3のどれとも違う見分け方になる
- メガドライブのベルトアクションには、ビルの中やエレベーターで戦う場面がよくある。見た目の方向に合う
- エレベーターラッシュは、画面が止まったせまい箱の中なので、タイムセールラッシュと同じ遊び方でも見た目と手ざわりがはっきり変わる
- もれを人の絵に描かないので、人を8種類にしても絵の手間はステージ3と同じくらい

### 気になるところ

- 背景が4つになる。ステージ1〜3の背景は1ステージに1組(3枚)だった。絵の手間が増え、「1つのステージの背景は45色まで」の決まりも、1つの階ごとに45色までへ直すことになる
- エレベーターの中の場面は新しい画面の形になる。ラッシュの中身(人が来る間隔、マーク、数え方)はタイムセールラッシュのコードを使えるが、見せ方は作り直し
- 波が4つとラッシュとボス戦で、いちばん長いステージになる(目安は6〜7分)。結果発表を長くしないように気をつける
- もれを周りにコードで出すので、仕分けの画面(人を2倍で見せる所)にも、人の後ろに明かりや小物を置く仕組みが要る

### 決めておきたいこと

- エレベーターラッシュを波3のあと(最上階の直前)にするか、波2のあと(ステージのまん中)にするか。おすすめは波3のあと。最上階へ上がる場面とつながり、最後のもり上がりになる
- 波の間の階の上がり方を、数字だけの短い場面にするか、階段を上がる場面にするか

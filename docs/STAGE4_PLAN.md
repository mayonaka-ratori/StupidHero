# ステージ4 高層ビル(超能力のヴィラン)の案

仕様を決める前の案です。はじめに雨の駅前、テレビ局、浮かんだ街の3つを出し、話し合って高層ビルにしました。そのあと、遊びの面と作りの面の2つからレビューを受けて直しました(下の「レビューで直したこと」)。決まったら、この案をもとに`docs/STAGE4.md`を書き、このファイルは消します。

## あらすじ

超能力のヴィランの親玉が、店とオフィスが入った高層ビルの最上階でパーティを開いている。ヒーローは1階から入り、階を上がりながらヴィランを見分けていく。最上階のパーティ会場で親玉と戦う。

## 決めたいこと

| 項目 | 案 |
|---|---|
| 舞台 | 店とオフィスが入った夜の高層ビル。波ごとに階が変わる |
| 悪党 | 超能力のヴィラン。見た目は普通の人 |
| 見分け方 | 周りを見る。ヴィランの近くでは小物が浮き、明かりの色が変わる |
| 結果発表で足す遊び | 見逃したヴィランが、その階の物を念力で浮かせて市民へ運ぶ。いつ行けを押して落とすかを選ぶ |
| 途中のイベント | 波3の答え合わせのあと、最上階へ上がるエレベーターラッシュ |
| ボス | ビルのオーナー(実は親玉)。ボス戦の途中で、客とシャンデリアをいっしょに浮かせる |
| 終わり | ボスを倒すと朝日が出て、ヒーローとオペレーターの短い終わりの場面 |
| 開き方 | ショッピングモールのボスを一度倒すと開く |

## 波と階

| 波 | 階 | 人数 | 奥の絵(窓の外) | 壊れる物 |
|---|---|---|---|---|
| 1 | 1階 ロビーとお店 | 4人 | 吹き抜けと入口の外の通り | 観葉植物、花のかざり |
| 2 | 18階 オフィス | 5人 | 近くのビルの明かり | 観葉植物、コピー機 |
| 3 | 35階 レストラン街 | 6人 | 遠くの夜景 | 水槽、ワインの棚 |
| 4 | 最上階 パーティ会場 | 6人と親玉 | 月と、はるか下の街 | シャンパンタワー、ピアノ |

- 人数は合わせて22人(ステージ3は18人)。答え合わせの画面は、高さ384の画面で7行までしか入らないので、どの波も7行以内にする
- 1つの波のヴィランは、波1は1〜2人、ほかは2〜3人(波4は2人と親玉)
- 背景は、奥の絵だけ階ごとに4枚にする。壁と床は「ふつうの階」と「パーティ会場」の2組にする。窓の外の景色が変わるだけでも、上がっていることは十分に分かる
- 背景の色の決まり(1つのステージで45色まで)は、「壁と床と奥の絵1枚の組ごとに45色まで」に直す
- 壊れる物は階ごとに2つずつ(観葉植物は2つの階で使う)。最上階の物は高くして、最後のステージらしく被害額が大きくなるようにする
- 波と波の間は、階の数字が上がっていく短い場面(1秒くらい)でつなぐ。エレベーターの中はラッシュのときに初めて見せる

## 見分け方:周りを見る

| ステージ | 見分け方 |
|---|---|
| 1 路地裏 | 1人をよく見る |
| 2 地下駐車場 | 前の人と比べる |
| 3 ショッピングモール | 少し待って動きを見る |
| 4 高層ビル | 周りを見る |

### もれの出し方

- もれは、人が仕分けの画面に出た瞬間からずっと出ている。待っても増えない。迷わせる所は「待つかどうか」ではなく、「そのもれは本人のせいか、周りのせいか」にする(ステージ3と同じにならないように)
- もれは2つだけ
  - 近くの小物が少し浮いている(ペン、名刺、グラスなど。3×3ドット以上)
  - 近くの明かりの色が紫に変わり、小さな火花が出る
- 置く場所は、階ごとに2か所に決める(例:左上の照明と、左下の机の上)。だれが出ても同じ場所に同じ物があるので、プレイヤーは見る場所を覚えられる
- 仕分けの画面では人が2倍で大きく出て、周りに残るのは左の細い所と頭の上だけ。置く場所はこの中に取る
- ステージ4だけ、「持ち物」の窓を「まわり」の窓にする。人の絵ではなく、置く場所の1か所を大きく映す。もれも窓の中に描く
- 「光と揺れを弱くする」がオンでも分かるように、点滅やゆれには頼らない。色が変わる、火花の絵が出る、で見せる
- 超能力の光は紫か橙にする。宇宙人の黄緑、ステージ2の赤紫、ヒーローの光の赤と水色は使わない
- 親玉はもれを出さない。ステージ3の親玉と同じく、見た目のおかしな所で見分ける

### 紛らわしい市民

周りのせいでもれに見える市民を入れる。理由はかならず絵で見えるようにする(3×3ドット以上)。ステージ3の「理由があってぎこちない市民」と同じ作り方。

- 手品の糸で小物を吊っている(糸が見える)
- 切れかけの蛍光灯の下にいる(蛍光灯の端が黒い)
- 風船を持っている(ひもが見える)

### 絵の手間を減らす工夫

もれは人の絵に描かず、周りにコードで出す。そのため市民とヴィランを同じ絵(同じ絵のキー)にできる。人を8種類にしても絵の数と起動の時間はふえにくい。はじめの案にあった「髪の毛が逆立つ」は人の絵の変化になるのでやめた。

## 出てくる人(8種類)

階ごとに2種類ずつ足す。上の階には、下の階の人も上がってくる。

| 階 | 見た目 | 見た目のくせ |
|---|---|---|
| 1階 | 花屋の店員 | 花びらが舞う |
| 1階 | 配達員 | 台車の荷物がゆれる |
| 18階 | 新人の会社員 | 書類を抱えている |
| 18階 | 清掃員 | モップを持っている |
| 35階 | シェフ | 湯気が上がる |
| 35階 | ウェイター | お盆にグラス |
| 最上階 | ドレスの女性 | 羽の飾り |
| 最上階 | 手品師 | 小物を糸で吊っている |

- 見た目のくせは、同じ見た目のヴィランにも同じように出す(くせだけで見分けられないように)
- 親玉の化けた姿は3つ(最上階の2種類と、ほかの階から1種類)
- 波1には、もれがはっきり分かるヴィランを1人入れる(練習)

## 結果発表で足す遊び:念力で運ぶ

「押すかどうか」ではなく、「いつ押すか」で迷わせる。

- 見逃したヴィランは、ヒーローが素通りしたあと、その階の壊れる物を1つ念力で浮かせる(浮いた絵を別に作らず、置いてある物をそのまま浮かせる)
- 浮いた物は、ほかの物の上を通りながら、通りがかりの市民の上へゆっくり運ばれる。この間は行けのマークが出ている
- 行けを押すと、ヒーローがヴィランを殴り、浮いていた物はその場の真下に落ちて壊れる。真下にほかの物があれば、それも壊れる
- 床の上で押せば安くすむ。高い物の上で押すと高くつく。待ちすぎると市民に当たる
- 押さなかったときは、物は壊れず、市民のけがになる。ヴィランは「逃がした」に数える
- 1つずつ順番に来る(ステージ3のUFOの順番待ちと同じ)
- SPECとSTAGE3にある「押すと被害額が増えるのはUFOだけ」の文は、ステージ4の念力も入れて直す

## 途中のイベント:エレベーターラッシュ

波3の答え合わせのあと、最上階へ上がるエレベーターの中で1回だけ起きる。乗ってくる人をヒーローがその場で殴ろうとするので、市民にだけ待てを押す。ステージ3のタイムセールラッシュの変化版。

### 場面

- 外が見えるガラス張りのエレベーター。後ろの窓の外を、夜景が下へ流れていく
- 上に階の数字(35→50)
- ヒーローは奥に立ち、扉の方を向いて構える。画面は横に動かない

### 遊び方

- 途中の階で扉が「チン」と開き、1人ずつ乗ってくる。全部で6人
- 乗ってきた人に待てのマークが出る。約1秒たつとヒーローが殴り、殴られた人は扉の外へ飛んでいく
- 待てを押すとヒーローが止まり、その人はエレベーターの奥へ入って立つ。奥に詰めて描き、次に乗ってくる人を隠さない
- ヴィランのもれは、その人の周りだけに出る(頭の上で小物が浮く、その人の横の階のボタンだけ紫に光る)。エレベーター全体には出さない
- 待てで通したヴィランは、奥で黙って立っている。最上階に着いたとき、エレベーター全体の明かりが一度だけ紫に光り、見逃していたことが分かる
- 最上階に着いて扉が開くとき、通した人が多いと「定員オーバー」のブザーが鳴るおまけ。数にも遊び方にも関わらない
- ラッシュの間は、ヒーローの構えの光を止める(もれとまぎれないように)
- 技は光のパンチだけ、巻きぞえなし、物は壊れない。ラッシュの数はほかの数字に入れない。ここはタイムセールラッシュと同じ

### タイムセールラッシュとの違い

| | タイムセールラッシュ | エレベーターラッシュ |
|---|---|---|
| 場所 | モールの通り | エレベーターの中(せまい、画面が動かない) |
| 人の来かた | 右から走ってくる | 扉が開くたびに1人乗ってくる |
| 見分け方 | 本人がくずれる | その人の周りの小物とボタンが変わる |
| 待てで通した人 | 左へ走って去る | 奥にたまっていく |
| 終わり方 | オペレーターの一言 | 最上階に着いて、見逃しの答え合わせ(明かり)と定員オーバーのおまけ |

### 流れ

1. 波3の答え合わせが終わる
2. ヒーローがエレベーターに乗り、扉が閉まる。「最上階へ!」の帯を出して止める
3. オペレーターのカットイン:「乗ってくる人、全員殴っちゃう!」「周りが光ったらヴィラン!市民にだけ待て!」
4. タップで始まる(タイムセールラッシュと同じ決まり)
5. 最上階に着いたら、ラッシュのまとめを1行出す(例:「エレベーター:撃破2/3・守った3/3」)。結果画面にも1行出す
6. 扉が開いて、そのまま波4の仕分けへ

答え合わせの前にラッシュを入れないので、波3の結果発表から答え合わせまでが長くならない。

## ボス:ビルのオーナー

- パーティの主催者。波4に化けた姿で紛れている
- 正体を現すと、会場のグラスや料理がいっせいに浮く
- ボス戦の途中で1回だけ、客とシャンデリアをいっしょに浮かせる。客には待て、シャンデリアには行けを、短い時間で選ぶ。ボス戦の画面は今は行けだけなので、この場面だけ待ても出す
- 倒すと、大きな窓の外に朝日が出る。ヒーローとオペレーターの短い終わりの場面(2〜3枚)
- 「全部のステージをクリアした」称号を足す

## そのほかに決めること

- ステージを選ぶ画面にカードが4枚になる。今の形では高さ468の画面でも絵が入らないので、2列にするか、指でずらして見る形にする
- フリープレイには、はじめは高層ビルを入れない(あとで足す)
- 共有に出す短い名前は「ビル」
- 称号の数(今は20個)、答え合わせの決め手の文(14文字まで)、8種類ぶんのセリフ

## レビューで直したこと

| はじめの案 | 直したあと | 理由 |
|---|---|---|
| 人数5、6、7、7と親玉 | 4、5、6、6と親玉 | 答え合わせの画面に入らない。ステージが長すぎる |
| もれは小物、明かりのちらつき、髪の逆立ち | 小物と明かりの色の2つ。いつも出ている | 髪は人の絵の変化になる。ときどき出すとステージ3と同じになる。ちらつきは「光と揺れを弱くする」で見えなくなる |
| 「持ち物」の窓はそのまま | 「まわり」の窓にする | 人の絵を映す窓には、周りのもれが映らない |
| 背景は階ごとに4組 | 奥の絵4枚、壁と床は2組 | 絵の手間を減らす |
| エレベーターで2人まとめて乗る | 1人ずつ | 2人いるとどちらのもれか分からない |
| エレベーター全体がちらつく | その人の周りだけ。全体は着いたときに1回だけ | 全体に出ると、そのあと乗る人を見分けられない |
| ラッシュは答え合わせの前 | 答え合わせのあと、波4の前 | 結果発表から答え合わせまでが長くなる |
| 定員オーバーのブザーが途中で鳴る | 着いたときのおまけだけ | 市民を守るほど悪いことに見える |
| 念力は押すと物が壊れ、押さないとけが人 | いつ押すかで被害額が変わる | UFOとほぼ同じになり、押す方が得で迷わない |
| ボス戦でシャンデリアを連打で止める | 客には待て、シャンデリアには行けを選ぶ | ふだんの連打と同じで、新しさがない |
| 終わりの場面なし | 朝日と短い終わりの場面、全クリアの称号 | 最後のステージなので |

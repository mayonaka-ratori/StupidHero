# やることと質問

開発のダッシュボード(`node tools/dashboard.mjs`)が、この表を読んで出します。作業をする人(AIも)は、始めるときと終わるときにここを直します(AIの手順は`CLAUDE.md`)。

- 状態は`todo`(まだ)、`doing`(やっている)、`done`(終わった)、`wait`(止まっている)のどれかを書く
- `wait`のときは、「止まっている理由」に何を待っているかを書く
- 人に決めてほしいことは「質問」の表に足す。答えが決まったら「答え」に書き、状態を`done`にする
- 表の形(列の数と順番)は変えない。ダッシュボードが読めなくなる

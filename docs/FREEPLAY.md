# フリープレイ仕様書(下書き)

仕分けのないステージ。ヒーローが自分の気分で殴ったり素通りしたりするので、プレイヤーは待てと行けだけで止める。ステージ1から3の遊び方(docs/SPEC.md、docs/STAGE2.md、docs/STAGE3.md)のうち、結果発表の決まりを土台にして、ここに書いたことだけを足したり変えたりする。まだ下書きなので、数字は遊びながら直す。

## ほかのステージとの違い

| | ステージ1〜3 | フリープレイ |
|---|---|---|
| 殴るか決めるのは | プレイヤーの仕分け | ヒーローの気分 |
| 見分けやすさ | 手がかりを組み合わせないと分からない | 一目で分かる |
| プレイヤーの仕事 | 仕分け、待て、行け | 待てと行けだけ |
| まちがいの原因 | プレイヤーの仕分け | ヒーローの思いこみ |
| オペレーター | 仕分けを手伝う | ヒーローの暴走にツッコむ |
| 長さ | 波3回とボス戦で3〜4分 | 90秒 |
| 答え合わせ | 波ごとにある | ない |

仕分けという「ヒーローに教える手間」がないので、「ヒーローが勝手に決めて、勝手にまちがえる」ところだけが残る。Stupid Heroらしさがいちばん出るステージにする。

## 決まったこと

| 項目 | 決定 |
|---|---|
| 長さ | 90秒。人が途切れなく来る。波もボスもない |
| 舞台と人 | 開いているステージの人をまぜる。背景は開いているステージの背景を順に回す |
| 開き方 | 路地裏のボスを一度倒すと開く |
| 称号 | フリープレイだけで取れる称号を足す |
| 記録 | フリープレイの記録を、ステージとは別に残す |

## 始め方

- ステージを選ぶ画面の下(「◀タイトルへ」の右)に「フリープレイ▶」のボタンを置く。カードは増やさない(カードが多いと、低い画面に入らないため)
- 開いていないときは、ボタンを暗くして鍵のマークをつける。押すと「路地裏をクリアすると遊べる」と出る
- 初めて遊ぶときだけ、掛け合いを3枚出す(下の「掛け合い」)。2回目からはすぐ始める

## 掛け合い

1. オペレーター:「今日は仕分けなし!ヒーローの好きにさせてみる」
2. ヒーロー:「まかせて!見れば分かるもん!」
3. オペレーター:「…絶対まちがえる。待てと行けで止めてね」

## ヒーローの気分

フリープレイの芯。ヒーローには2つの気分があり、前ぶれなしに切りかわる。

| 気分 | ヒーローがすること | プレイヤーがすること |
|---|---|---|
| 殴りたい気分 | 目の前の人に全員殴りかかる。おばあさんにも | 市民には待てを押して止める |
| 平和な気分 | 全員に手を振って素通りする。ナイフを持ったモヒカンにも | 悪さを始めたワルに行けを押す |

- 1つの気分は8〜15秒続く(毎回ばらばら)。90秒で7〜9回くらい切りかわる
- 最初の気分は、殴りたい気分にする(待てから覚えるほうが分かりやすいため)
- 今どちらの気分かを、いつでも分かるようにする
  - ヒーローの体のまわりの光の色(殴りたい気分は赤、平和な気分は水色)
  - ヒーローの顔(殴りたい気分は怒った顔、平和な気分はにこにこ)
  - 画面の左上の札(「殴りたい気分」「平和な気分」)
- 気分が切りかわるときは、ヒーローの頭の上に一言を出す(殴りたい気分:「今日は全員ワルに見える!」、平和な気分:「みんないい人!」)
- ときどき、殴りかかる途中で気分が変わり、急に手を振りだす(その人は殴らない)。逆に、手を振っている途中で急に殴りかかることもある。1回のプレイで2〜3回まで

## 人

- 開いているステージの人をまぜて出す。まだ開いていないステージの人は出さない(ネタばれしないように)。先へ進むほど、にぎやかになる
- ワルは一目で分かる見た目にする。ステージ1から3の「手がかり」を丸出しにした絵

| ステージ | 一目で分かるワル | 市民 |
|---|---|---|
| 路地裏 | ナイフを振りかざしたモヒカン | おばあさん、買い物袋の女性など、ステージ1の市民 |
| 地下駐車場 | 顔をバンダナで隠して金属バットを持ったギャング | ステージ2の市民 |
| ショッピングモール | 頭から触角が出て、肌が緑の宇宙人 | ステージ3の市民 |

- ワルと市民はだいたい半々。同じ見た目が続きすぎないようにする
- 人は2〜3秒おきに来る。90秒で30〜40人くらい

## 待てと行け

今の決まり(docs/SPEC.md の「待てと行け」)のまま使う。違うのは次の所だけ。

- 待てのマークは、殴りたい気分のヒーローが殴りに行く相手全員に出る
- 行けのマークは、平和な気分のヒーローが素通りしたワルが悪さを始めたときに出る
- ワルの悪さは、そのステージの悪さをそのまま使う
  - モヒカンは、ひったくりや突き飛ばし(行けで追い打ち)
  - ギャングは、口笛で仲間を呼んで集まる(行けでまとめて吹き飛ばす。3秒で車に乗って逃げる)
  - 宇宙人は、UFOを呼んで通りがかりの市民をさらう(行けでUFOを落とす)
- ギャングの仲間呼びとUFOは、フリープレイでもそのまま使う。遊んでみて画面がごちゃごちゃしすぎるなら、あとで外す
- 本性ちらりとヒーローの決めつけは出さない(見た目で分かるので要らない)。代わりに、ヒーローは気分に合わせた一言を言う(殴りたい気分:「悪そうな顔!」、平和な気分:「いい笑顔!」。相手がワルでも市民でも同じ)
- 早送りは使えない(ずっと待てと行けを押す場面なので)

## オペレーター

仕分けていないので、「…ワルにしたの、私だけど」のような、自分の仕分けを責める一言は出さない。ヒーローの思いこみにツッコむ一言にする。

| 場面 | 一言の例 |
|---|---|
| 殴りたい気分で、市民に殴りかかる | 「おばあちゃんだよ!?」「どう見ても市民!」 |
| 平和な気分で、ワルを素通りする | 「どう見てもナイフ持ってる!」「なんで今スルーした!?」 |
| 気分が変わった | 「あ、また気分が変わった」「今度は平和モード…」 |
| 待てで市民を守った | 「セーフ!」「あぶなかった…」 |
| 市民を殴ってしまった | 「見れば分かるって言ったよね!?」 |

- ヒーローは、市民を殴っても謝らない。「でも悪そうな顔だった!」と言いはる

## 数え方

今の数字をそのまま使う(悪党を倒した、市民のけが、逃がした、被害額)。仕分けがないので「仕分け正解」は出さず、代わりに次を足す。

| 数字 | 数え方 |
|---|---|
| 待てで守った | 殴りたい気分のヒーローを、待てで市民から止めた人数 |
| 行けで倒した | 平和な気分で素通りしたワルを、行けで倒した人数(まとめて吹き飛ばした人、UFOごと倒した人も入る) |
| 気分が変わった回数 | そのプレイで気分が切りかわった回数 |

## 結果画面

ステージ1から3と同じ画面で、次を変える。

- 称号は、フリープレイの称号とステージの称号の両方から、上から順に調べる(下の「称号」)
- 数字の窓は、待てで守った、行けで倒した、市民のけが、逃がした、被害額の順
- 「もう一回」はフリープレイをもう一度。「タイトルへ」はタイトルへ
- 共有カードの右上のステージ名は「フリープレイ」

## 称号

フリープレイだけで取れる称号を3つ足して、全部で20個にする。

| 称号 | 条件 | ヒント(称号の一覧) | 勝利ポーズ |
|---|---|---|---|
| ヒーローのお守り役 | 市民のけがが0で、逃がしたワルが0 | フリープレイで、だれも傷つけず、だれも逃がさない | 決めポーズ |
| 気分屋の相棒 | 待てで市民を10人以上守り、行けでワルを10人以上倒した | フリープレイで、待ても行けも10回ずつ決める | 腕組みでドヤ顔 |
| なすがまま | 待ても行けも一度も押さなかった | フリープレイで、何もしない | 頭をかいて照れ笑い |

- 順番は、ヒーローのお守り役を「完全無欠のヒーロー」のすぐあと、なすがままを「市民の天敵」のすぐ前、気分屋の相棒を「待ての達人」のすぐ前にする
- フリープレイでは、ステージだけの称号(ボスの親友、連打の申し子、一網打尽、ギャングの運転手、宇宙人の案内係、タイムセールの守り神、UFOハンター)は取れない。取れる称号の数は、開いているステージによって変わる

## 記録

- ステージとは別に、フリープレイの記録を残す:待てで守った数、行けで倒した数、最少負傷、最高被害額のいちばん良いもの
- ステージを選ぶ画面の「フリープレイ▶」のボタンに、いちばん良い記録を小さく出す(「守った12・倒した9」など)

## 音

- フリープレイの曲を1曲足す(速めで、にぎやかな曲。90秒の間ずっとくり返す)
- 気分が切りかわる音を足す(殴りたい気分は低い「ドン!」、平和な気分は明るい「ポワン」)

## 絵

- 一目で分かるワル3人(ナイフを振りかざしたモヒカン、バンダナで顔を隠したギャング、触角の出た宇宙人)。今のワルの絵をもとに描き足す
- ヒーローの気分の光(赤と水色)。今のヒーローの光の色を変えて使う
- 左上の気分の札

## まだ決めていないこと

- 背景を何秒ごとに回すか(30秒ごとなら、90秒で3つのステージを1回ずつ通る)
- 人の来る間隔と、気分の長さ(遊んで直す)

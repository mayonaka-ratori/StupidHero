# フリープレイ仕様書(下書き)

仕分けのないステージ。ヒーローが見た目だけでルールを決めつけ、その通りに殴ったり素通りしたりするので、プレイヤーは待てと行けだけで直す。ステージ1から3の結果発表の決まり(docs/SPEC.md、docs/STAGE2.md、docs/STAGE3.md)を土台にして、ここに書いたことだけを足したり変えたりする。まだ下書きなので、数字は遊びながら直す。

5つの人物(通勤電車で遊ぶ会社員、やりこみ勢、笑える場面を共有する人、ゲームデザイナー、子どもと60代の人)になりきった検討を2回して、その意見を入れてある。

## ほかのステージとの違い

| | ステージ1〜3 | フリープレイ |
|---|---|---|
| 殴るか決めるのは | プレイヤーの仕分け | ヒーローの決めつけ |
| 見分けやすさ | 手がかりを組み合わせないと分からない | ワルか市民かは一目で分かる |
| 読むもの | その人がワルか市民か | ヒーローがその人に何をするか、それが合っているか |
| プレイヤーの仕事 | 仕分け、待て、行け | 待てと行けだけ |
| まちがいの原因 | プレイヤーの仕分け | ヒーローの思いこみ |
| オペレーター | 仕分けを手伝う | ヒーローの思いこみにツッコむ |
| 終わり方 | 波3回とボス戦 | 山札の人(27場面)が全員通ったら終わり。ボスなし |
| 記録 | 最多撃破など | クリアまでの時間 |
| 答え合わせ | 波ごとにある | ない |

仕分けという「ヒーローに教える手間」がないので、「ヒーローが勝手に決めて、勝手にまちがえる」ところだけが残る。Stupid Heroらしさがいちばん出るステージにする。

## 決まったこと

| 項目 | 決定 |
|---|---|
| 形 | 波3回。波の始めに、ヒーローが見た目だけでルールを決めつける。ルールは画面に出るので、プレイヤーはヒーローが何をするかを先に読んで構える |
| 終わり方 | 時計で切らない。山札の人が全員通ったら波が終わる。うまく遊んで約100秒 |
| 記録 | クリアまでの時間。逃がしたワルと市民のけが1人につき3秒を足す |
| 舞台と人 | 開いているステージの人をまぜる。背景は波ごとに、開いているステージの背景を1つずつ使う |
| 開き方 | 路地裏のボスを一度倒すと開く |
| ギャングとUFO | ギャングの仲間呼びとUFOは、フリープレイでもそのまま使う。遊んでみて画面がごちゃごちゃしすぎるなら、あとで外す |
| 行けの空押し | マークがないときに押すと1.0秒効かなくなり、押し直すたびに数え直す |
| ルールの言い直し | 波3で1回 |
| 称号 | フリープレイだけで取れる称号を3つ足す |

## 始め方

- ステージを選ぶ画面の下(「◀タイトルへ」の右)に「フリープレイ▶」のボタンを置く。カードは増やさない(カードが多いと、低い画面に入らないため)
- 開いていないときは、ボタンを暗くして鍵のマークをつける。押すと「路地裏をクリアすると遊べる」と出る
- 初めて遊ぶときだけ、掛け合いを3枚出す(下の「掛け合い」)。2回目からはすぐ始める
- 路地裏しか開いていない人には、結果画面で一度だけ「ステージを進めると、出てくる人が増えるよ」と出す

## 掛け合い

1. オペレーター:「今日は仕分けなし!ヒーローの好きにさせてみる」
2. ヒーロー:「まかせて!見れば分かるもん!」
3. オペレーター:「…絶対まちがえる。待てと行けで直してね」

## 3回の波

| 波 | ヒーローの決めつけ | 本当は | プレイヤーの仕事 |
|---|---|---|---|
| 1 | 「ここはワルだらけだな!」全員に殴りかかる | ほとんど市民 | 市民に待て(待てだけを覚える) |
| 2 | 「ここにはワルはいなさそうだ!」全員に手を振って素通り | ワルがたくさん | 悪さを始めたワルに行け(行けだけを覚える) |
| 3 | 「風船の人はワル!」のような、小物のルール | ルールと関係なく、ワルと市民がまざる | ルールに当てはまる市民に待て、当てはまらないワルに行け(両方を使い分ける) |

- 決めつけと本当は、わざと逆にする。「ワルだらけ」の波はほとんど市民で、「ワルはいない」の波はワルだらけ。ヒーローのおバカさが、そのまま笑いと忙しさになる
- 決めつけの理由は、見た目だけのこじつけにする(「暗いからワルだらけ!」「明るいからいい人ばかり!」など。背景ごとに2〜3通り)
- 波1と波2の順番は変えない(待てから覚えるほうが分かりやすいため)
- 波1と波2はやさしく、波3で難しくする(下の「波3」)

### 波の始め

- 「WAVE1」の帯のあと、ヒーローの決めつけと、オペレーターのツッコミ(「暗いってだけで!?」など)を出す。その間はクリアまでの時間を止める。画面をタップすると飛ばせる
- 左上に、ルールの札を出す。札は絵とひらがなで、字が読めなくても分かるようにする
  - 波1:拳の絵と「みんなワル」
  - 波2:手のひらの絵と「みんないいひと」
  - 波3:小物の絵(風船など)に拳、それ以外に手のひら。「ふうせん=ワル」
- ヒーローのまわりの光は、殴りかかるときは赤いトゲトゲの形、素通りするときは水色の丸い形にする(色だけで見分けないように)。「光と揺れを弱くする」がオンなら、点滅させずに、同じ形のふち取りにする

### 波3

波3は、ルールを先に読んだ人が得をするように作る。ワルか市民かは一目で分かるので、ルールを読まずにマークだけ見ても解けないようにする。

- 小物は3つ。どれも今の人の絵にない、大きく目立つものにする(今の絵には、警備員とダンスの学生の帽子、モヒカンのサングラス、買い物袋の女性とおじさんの袋がもともと付いているので、それとまぎれないように)

| 小物 | 付ける場所 | 色 |
|---|---|---|
| 風船 | 頭の上に浮かぶ(ひもで手につながる) | 黄色 |
| とんがり帽子 | 頭(モヒカンの髪と宇宙人の触角は帽子を突き抜ける) | 濃い緑 |
| 大きな紙袋 | 手に持つ(6×8ドット以上。買い物袋の女性とおじさんには付けない) | 茶色 |

- 小物の色は、赤、水色、赤紫、黄緑を使わない(ヒーローの光、ステージ2の塗り替えの色、宇宙人のくずれの色とまぎれないように)
- 地下駐車場の市民の小物(腕章、タオルなど)は、オレンジか紫に塗る(風船の黄色とまぎれないように)
- 人の絵に重ねて描く小さな絵にし、見た目ごとに付ける場所の表を作る。ワルの目印(ナイフ、バンダナ、触角)は隠さない
- ヒーローは3つのうち1つを選んで「〇〇の人はワル!」と決めつける。当てはまる人には全員殴りかかり、当てはまらない人は全員素通りする。殴りかかるときの吹き出しに、小物の絵を出す(「〇〇だからワル!」)
- プレイヤーは次の4通りを見分ける

| | ルールに当てはまる(殴りかかる) | 当てはまらない(素通りする) |
|---|---|---|
| 本当は市民 | 待てで止める | 何もしない |
| 本当はワル | 何もしない(ヒーローが正しい) | 悪さを始めたら行け |

- 波3だけ難しくする
  - マークのゆっくり(0.6倍)をやめ、ため(WINDUP)を1.08秒から0.8秒にする。マークは約0.9秒になる。先にルールと小物を読んで構えた人だけが間に合う
  - 素通りしたワルが悪さをしている間も、ヒーローは歩き続ける。次の人のマークと行けのマークが重なる場面ができる
    - 歩き続けるのは、モヒカンの悪さ(ナイフで脅す)のときだけ。ギャングの集合とUFOは、ほかのステージと同じくヒーローが待つ(カメラがそちらを向くため)
    - 行けのマークが2つ同時に出ていたら、行けは先に出たほうに効く。ヒーローが待てのマークの最中なら、その場から光の拳を飛ばして倒す(ためは続く)
  - 人と人の間は96ドット(悪さの相手が72ドット先に立つので、それと重ならないように)
- ルールの言い直し:波3の6人目が通ったあとに1回、ヒーローがルールを言い直す(「やっぱり帽子の人がワル!」)。言い直す瞬間は時計を1.5秒止め、札が変わるのを見せる。オペレーターは「また変えた!?」とツッコむ。ゆっくりモードでも言い直す(時計は3秒止める)

## 人

- 開いているステージの人をまぜて出す。まだ開いていないステージの人は出さない(ネタばれしないように)。先へ進むほど、にぎやかになる
- ワルは一目で分かる見た目にする。ステージ1から3の手がかりを丸出しにした絵

| ステージ | 一目で分かるワル | 市民 |
|---|---|---|
| 路地裏 | ナイフを振りかざしたモヒカン | おばあさん、買い物袋の女性など、ステージ1の市民 |
| 地下駐車場 | 顔をバンダナで隠して金属バットを持ったギャング | ステージ2の市民 |
| ショッピングモール | 頭から触角が出て、肌が緑の宇宙人 | ステージ3の市民 |

- 人の並べ方は今のステージと同じで、ヒーローが右へ進む。人と人の間は、波1と波2が104ドット(今と同じ)、波3が96ドット
- 毎回、同じ数のチャンスが来るように、山札のように配る(記録が並び方の運で決まらないように)。「行けのチャンス」は人数ではなく、行けを押す場面の数で数える(ギャングの組は1場面)

| 波 | 人数 | 待てのチャンス(殴りかかられる市民) | 行けのチャンス(素通りされるワル) | ヒーローが正しい人 |
|---|---|---|---|---|
| 1 | 8人 | 6 | 0 | ワル2 |
| 2 | 7人 | 0 | 5 | 市民2 |
| 3 | 12人 | 3 | 3 | 6(殴られるワル3、素通りされる市民3) |
| 合計 | 27人 | 9 | 8 | 10 |

- 表の数は場面の数。ギャングの組は2人で1場面なので、組が出ると人数は1人ずつ増える(27〜29人)。「ヒーローだけなら10/27人」も場面で数える
- 波3の12場面は、言い直しの前と後の半分ずつに分け、どちらも4通りが偏らないように配る。言い直すのは前の半分が通ったあと(ふつうは6人目、ギャングの組が前の半分にいれば7人目)
- 言い直しのあとの半分には、前のルールの小物を持った、ルールに当てはまらない人を入れる(札が変わったのを見ないとまちがえるように)
- ギャングは、フリープレイでは2人の組だけにし、1つの波に1組まで(集合から車で逃げるまでがいちばん長く止まる場面なので)。組は行けのチャンス(素通りされる役)にだけ出す(殴られる役だと、1組で2人ぶんの当たりになるため)
- どのワルが出るかは、開いているステージで決める(記録が運で変わらないように)。開いていれば、波2にはギャング1組と宇宙人1人を必ず入れる。波3の行けのチャンスには、ギャングか宇宙人のどちらか1つだけを入れ、ほかはモヒカンにする(歩き続ける場面を残すため)
- ギャングの集合とUFOは同時に出さない。1つ終わるまで、次のギャングは口笛を吹かず、次の宇宙人は合図を送らずに待つ

## 待てと行け

今の決まり(docs/SPEC.md の「待てと行け」)のまま使う。違うのは次の所だけ。

- 待てのマークは、ヒーローが殴りかかる相手全員に出る(ワルにも出る。見た目で分かるので、押さないのが正解)
- **ワルに待てを押したときの取り返し**:待てで止めたワルは、すぐ悪さを始めて行けのマークが出る。行けで倒せば「逃がした」に数えない(ヒーローは「ほら、やっぱりワルじゃん!」)。「待てで止めた相手をあとで行けで殴れない」の例外で、フリープレイだけの決まり
- 行けのマークは、素通りしたワルが悪さを始めたときに出る
- ワルの悪さ
  - モヒカンは、フリープレイでは「ナイフで脅す」にする(けがはさせない。行けが間に合えば、だれも傷つかない)。行けを押さずに3秒たつと、財布を奪って逃げ、そのとき市民のけがになる
  - ギャングは、口笛で仲間を呼んで集まる(行けでまとめて吹き飛ばす。3秒で車に乗って逃げる)。車はどの背景でも、画面の右から走ってくる
  - 宇宙人は、UFOを呼んで通りがかりの市民をさらう(行けでUFOを落とす)
- 本性ちらりは出さない(見た目で分かるので要らない)。ヒーローの決めつけは、ルールに合わせた一言にする(下の「ヒーロー」)
- **空押し**:マークがないときに行けを押すと、ヒーローが「?」と振り向き、1.0秒だけ行けが効かない。その間に押し直すと、そこから1.0秒数え直す。連打すると一度も効かず、見て押す人は困らない。待ても同じ(ヒーローが「?」と立ち止まる)。フリープレイだけの決まり
- マークの長さとゆっくり(約1.5秒、0.6倍)は、波1と波2は今のまま。波3は上の「波3」の通り短くする
- 早送りは使えない

## クリアまでの時間

- 波1の始めから、波3の最後の人が通るまでの時間を数える。波の始めの決めつけと、言い直しで止めている時間は数えない
- 待てで止めるのが早いほど、行けを早く押すほど、速く終わる
- 逃がしたワル1人、市民のけが1人につき、3秒を足す(ワルに待てを押すと、殴るより早く次へ進むので、その得を消すため)
- 画面の左上(ルールの札の下)に、時間を小さく出す
- ゆっくりモードで遊んだ記録は、ふつうの記録とは別に残し、「ゆっくり」の印をつける

## ヒーロー

- 波の始めの決めつけは、背景と波ごとに2〜3通りから選ぶ
- 殴りかかるときと素通りするときの一言は、それぞれ見た目ごとに5通り以上から選び、同じ文を続けて出さない
  - 殴りかかる:「悪そうな顔!」「その袋、あやしい!」など
  - 素通り:「いい笑顔!」「そのバット、野球だよね!」など
- 市民を殴っても謝らない。「でもルール通りだし!」と言いはる

## オペレーター

仕分けていないので、「…ワルにしたの、私だけど」のような、自分の仕分けを責める一言は出さない。ヒーローの思いこみにツッコむ一言にする。

- どの場面も5通り以上から選び、同じ文を続けて出さない。毎回は言わず、1つの波で4回くらいにする
- 同じ場面の2回目、3回目で言い方を変えていく(1回目「おばあちゃんだよ!?」、5回目「もうわざとでしょ」)

| 場面 | 一言の例 |
|---|---|
| 波の始めの決めつけ | 「暗いってだけで!?」「その決め方、雑すぎ!」 |
| ルールに当てはまる市民に殴りかかる | 「おばあちゃんだよ!?」「風船持ってるだけ!」 |
| ルールに当てはまらないワルを素通り | 「どう見てもナイフ持ってる!」「なんで今スルーした!?」 |
| ルールを言い直した | 「また変えた!?」「さっきと違うじゃん!」 |
| 待てで市民を守った | 「セーフ!」「あぶなかった…」 |
| 市民を殴ってしまった | 「見れば分かるって言ったよね!?」 |
| 待ても行けも押さない時間が続く | 「…押して?」「ねえ、見てる?」「もう知らない」(だんだんあきらめていく。ワルの悪さを待っている間など、押さないのが正しいときは言わない) |

## ゆっくりモード

一時停止のメニューの「ゆっくりモード」がオンなら、次を1.5倍にする。人数とチャンスの数は変えない(山札で終わるので、そのぶん長く遊ぶ)。

- 人と人の間
- マークの長さ(マークの間のヒーローの速さを下げる。波3も1.5倍)
- 悪さのワルが逃げるまで、ギャングが車に乗るまでと車が走る時間、UFOの吸い上げ
- ルールの言い直しで止める時間(1.5秒を3秒に)

取れる称号は変わらない。

## 数え方

今の数字をそのまま使う(悪党を倒した、市民のけが、逃がした、被害額)。仕分けがないので「仕分け正解」は出さず、代わりに次を足す。

| 数字 | 数え方 |
|---|---|
| クリアまでの時間 | 上の「クリアまでの時間」 |
| 待てで守った | 殴りかかったヒーローを、待てで市民から止めた人数(9人まで) |
| 行けで決めた | 行けを押してワルを倒した場面の数(ギャングをまとめて吹き飛ばしても、UFOを落としても1回。8回まで。ワルに待てを押したあとの取り返しは数えない) |
| 空押し | マークがないときに押した回数 |
| ヒーローの決めつけの当たり | ヒーローだけならどれだけ当たっていたかと、プレイヤーが直したあとの数を並べる(「ヒーローだけなら10/27人、あなたが直して25/27人」) |

## 結果画面

ステージ1から3と同じ画面で、次を変える。

- 称号は、フリープレイの称号から先に調べる(下の「称号」)
- 数字の窓は、クリアまでの時間(大きく)、待てで守った、行けで決めた、市民のけが、逃がした、被害額の順。いちばん下に小さく「ヒーローだけなら10/27人、あなたが直して25/27人」
- いちばんひどい場面の候補を足す(ボスがいないため)
  - 素通りのヒーローがワルに笑顔で手を振った瞬間。文はワルごとに変える(「ナイフ男に笑顔で手を振った!」「ギャングの車に手を振って見送った!」「UFOに手を振った!」)
  - 拳が当たる寸前に待てで止めた瞬間(「ギリギリセーフ!」)
- 共有の文の1行目は、ルールと場面をつなげる(「『風船の人はワル!』でおばあちゃんに全力パンチ!」)。写真の角に、ルールの札を小さく入れる
- 共有カードの数字は、結果画面の数字の窓とそろえる。右上のステージ名は「フリープレイ」
- 「もう一回」はフリープレイをもう一度。「タイトルへ」はタイトルへ

## 称号

フリープレイだけで取れる称号を3つ足して、全部で20個にする。

| 称号 | 条件 | ヒント(称号の一覧) | 勝利ポーズ | ひとこと |
|---|---|---|---|---|
| ヒーローのお守り役 | ヒーローがなぐった市民とワルにやられた市民が0で、逃がしたワルが0(まきぞえは数えない) | フリープレイで、だれも傷つけず、だれも逃がさない | 決めポーズ | 「おバカ、全部止めたね!」 |
| ヒーローの通訳 | 待てのチャンスと行けのチャンスを、それぞれ8割以上決め(待て8人以上、行け7回以上)、空押しが3回まで | フリープレイで、待ても行けもほとんど決める | 腕組みでドヤ顔 | ヒーロー「ぼくの言いたいこと、分かってたんだね!」 |
| なすがまま | 効いた待てと行けが0(空押しは数えない) | フリープレイで、ヒーローに全部まかせる | 頭をかいて照れ笑い | 「…もう知らない」 |

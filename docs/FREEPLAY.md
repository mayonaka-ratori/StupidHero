# フリープレイ仕様書(下書き)

仕分けのないステージ。ヒーローが見た目だけでルールを決めつけ、その通りに殴ったり素通りしたりするので、プレイヤーは待てと行けだけで直す。ステージ1から3の結果発表の決まり(docs/SPEC.md、docs/STAGE2.md、docs/STAGE3.md)を土台にして、ここに書いたことだけを足したり変えたりする。まだ下書きなので、数字は遊びながら直す。

## ほかのステージとの違い

| | ステージ1〜3 | フリープレイ |
|---|---|---|
| 殴るか決めるのは | プレイヤーの仕分け | ヒーローの決めつけ |
| 見分けやすさ | 手がかりを組み合わせないと分からない | ワルか市民かは一目で分かる |
| 読むもの | その人がワルか市民か | ヒーローがその人に何をするか、それが合っているか |
| プレイヤーの仕事 | 仕分け、待て、行け | 待てと行けだけ |
| まちがいの原因 | プレイヤーの仕分け | ヒーローの思いこみ |
| オペレーター | 仕分けを手伝う | ヒーローの思いこみにツッコむ |
| 長さ | 波3回とボス戦で3〜4分 | 波3回で90秒。ボスなし |
| 答え合わせ | 波ごとにある | ない |

仕分けという「ヒーローに教える手間」がないので、「ヒーローが勝手に決めて、勝手にまちがえる」ところだけが残る。Stupid Heroらしさがいちばん出るステージにする。

## 決まったこと

| 項目 | 決定 |
|---|---|
| 長さ | 波3回で90秒(25秒、25秒、40秒)。人が途切れなく来る。ボスはない |
| 芯になる遊び | 波の始めに、ヒーローが見た目だけでルールを決めつける。ルールは画面に出るので、プレイヤーはヒーローが何をするかを先に読んで構える |
| 舞台と人 | 開いているステージの人をまぜる。背景は波ごとに、開いているステージの背景を1つずつ使う |
| 開き方 | 路地裏のボスを一度倒すと開く |
| ギャングとUFO | ギャングの仲間呼びとUFOは、フリープレイでもそのまま使う。遊んでみて画面がごちゃごちゃしすぎるなら、あとで外す |
| 称号 | フリープレイだけで取れる称号を3つ足す |
| 記録 | フリープレイの記録を、ステージとは別に残す |

## 始め方

- ステージを選ぶ画面の下(「◀タイトルへ」の右)に「フリープレイ▶」のボタンを置く。カードは増やさない(カードが多いと、低い画面に入らないため)
- 開いていないときは、ボタンを暗くして鍵のマークをつける。押すと「路地裏をクリアすると遊べる」と出る
- 初めて遊ぶときだけ、掛け合いを3枚出す(下の「掛け合い」)。2回目からはすぐ始める
- 路地裏しか開いていない人には、結果画面で一度だけ「ステージを進めると、出てくる人が増えるよ」と出す

## 掛け合い

1. オペレーター:「今日は仕分けなし!ヒーローの好きにさせてみる」
2. ヒーロー:「まかせて!見れば分かるもん!」
3. オペレーター:「…絶対まちがえる。待てと行けで直してね」

## 3回の波

| 波 | 長さ | ヒーローの決めつけ | 本当は | プレイヤーの仕事 |
|---|---|---|---|---|
| 1 | 25秒 | 「ここはワルだらけだな!」全員に殴りかかる | ほとんど市民 | 市民に待て(待てだけを覚える) |
| 2 | 25秒 | 「ここにはワルはいなさそうだ!」全員に手を振って素通り | ワルがたくさん | 悪さを始めたワルに行け(行けだけを覚える) |
| 3 | 40秒 | 「帽子の人はワル!」のような、小物のルール | ルールと関係なく、ワルと市民がまざる | ルールに当てはまる市民に待て、当てはまらないワルに行け(両方を使い分ける) |

- 決めつけと本当は、わざと逆にする。「ワルだらけ」の波はほとんど市民で、「ワルはいない」の波はワルだらけ。ヒーローのおバカさが、そのまま笑いと忙しさになる
- 決めつけの理由は、見た目だけのこじつけにする(「暗いからワルだらけ!」「明るいからいい人ばかり!」など。背景ごとに2〜3通り)
- 波1と波2の順番は変えない(待てから覚えるほうが分かりやすいため)

### 波の始め

- 「WAVE1」の帯のあと、ヒーローの決めつけと、オペレーターのツッコミ(「暗いってだけで!?」など)を出す。その間は時計を止める
- 左上に、ルールの札を出す。札は絵とひらがなで、字が読めなくても分かるようにする
  - 波1:拳の絵と「みんなワル」
  - 波2:手のひらの絵と「みんないいひと」
  - 波3:小物の絵(帽子など)に拳、それ以外に手のひら。「ぼうし=ワル」
- ヒーローのまわりの光は、殴りかかるときは赤いトゲトゲの形、素通りするときは水色の丸い形にする(色だけで見分けないように)。「光と揺れを弱くする」がオンなら、点滅させずにふち取りにする

### 波3のルール

- 波3の人は、目立つ小物を1つ持つか持たない。小物は帽子、サングラス、紙袋の3つ。人の絵に重ねて描く小さな絵にする(どの見た目にも付けられるように)
- ヒーローは3つのうち1つを選んで「〇〇の人はワル!」と決めつける。当てはまる人には全員殴りかかり、当てはまらない人は全員素通りする
- ワルか市民かと、小物を持っているかは関係なく配る。プレイヤーは次の4通りを見分ける

| | ルールに当てはまる(殴りかかる) | 当てはまらない(素通りする) |
|---|---|---|
| 本当は市民 | 待てで止める | 何もしない |
| 本当はワル | 何もしない(ヒーローが正しい) | 悪さを始めたら行け |

- 気まぐれ:波3の途中で1〜2回、ヒーローがルールを言い直す(「やっぱりサングラスの人がワル!」)。言い直す瞬間は時計を1.5秒止め、札が変わるのを見せる。待てか行けのマークが出ている間は言い直さない。ゆっくりモードでは言い直さない

## 人

- 開いているステージの人をまぜて出す。まだ開いていないステージの人は出さない(ネタばれしないように)。先へ進むほど、にぎやかになる
- ワルは一目で分かる見た目にする。ステージ1から3の手がかりを丸出しにした絵

| ステージ | 一目で分かるワル | 市民 |
|---|---|---|
| 路地裏 | ナイフを振りかざしたモヒカン | おばあさん、買い物袋の女性など、ステージ1の市民 |
| 地下駐車場 | 顔をバンダナで隠して金属バットを持ったギャング | ステージ2の市民 |
| ショッピングモール | 頭から触角が出て、肌が緑の宇宙人 | ステージ3の市民 |

- 人の並べ方は今のステージと同じで、ヒーローが右へ進む。人と人の間は、波1が104ドット(今と同じ)、波2が92ドット、波3が80ドットと、少しずつ詰める
- 毎回、待てと行けのチャンスの数が同じになるように、山札のように配る(記録が並び方の運で決まらないように)

| 波 | 人数 | 待てのチャンス(殴りかかられる市民) | 行けのチャンス(素通りされるワル) | ヒーローが正しい人 |
|---|---|---|---|---|
| 1 | 10人 | 8 | 0 | ワル2 |
| 2 | 11人 | 0 | 8 | 市民3 |
| 3 | 20人 | 5 | 5 | 10(殴られるワル5、素通りされる市民5) |
| 合計 | 41人 | 13 | 13 | 15 |

- ギャングは2〜3人が続けて来て組になる(フリープレイでは、続けて来たギャングが同じ組)。車はどの背景でも、画面の右から走ってくる
- ギャングの集合とUFOは同時に出さない。1つ終わるまで、次のギャングは口笛を吹かず、次の宇宙人は合図を送らずに待つ

## 待てと行け

今の決まり(docs/SPEC.md の「待てと行け」)のまま使う。違うのは次の所だけ。

- 待てのマークは、ヒーローが殴りかかる相手全員に出る(ワルにも出る。ワルを待てで止めると、今と同じく「逃がした」になる。見た目で分かるので、押さないのが正解)
- 行けのマークは、素通りしたワルが悪さを始めたときに出る
- ワルの悪さは、そのステージの悪さをそのまま使う
  - モヒカンは、ひったくりや突き飛ばし(行けで追い打ち)
  - ギャングは、口笛で仲間を呼んで集まる(行けでまとめて吹き飛ばす。3秒で車に乗って逃げる)
  - 宇宙人は、UFOを呼んで通りがかりの市民をさらう(行けでUFOを落とす)
- 本性ちらりは出さない(見た目で分かるので要らない)。ヒーローの決めつけは、ルールに合わせた一言にする(下の「ヒーロー」)
- **行けの空押し**:マークがないときに行けを押すと、ヒーローが「?」と振り向き、0.4秒だけ次の行けが効かない。何も減らないが、連打より見て押すほうが速くなる(フリープレイだけの決まり)
- マークの長さとゆっくり(約1.5秒、0.6倍)は、今のまま
- 早送りは使えない(ずっと待てと行けを押す場面なので)

## ヒーロー

- 波の始めの決めつけは、背景と波ごとに2〜3通りから選ぶ
- 殴りかかるときと素通りするときの一言は、それぞれ見た目ごとに3〜5通りから選び、同じ文を続けて出さない
  - 殴りかかる:「悪そうな顔!」「その袋、あやしい!」など
  - 素通り:「いい笑顔!」「そのバット、野球だよね!」など
- 市民を殴っても謝らない。「でもルール通りだし!」と言いはる

## オペレーター

仕分けていないので、「…ワルにしたの、私だけど」のような、自分の仕分けを責める一言は出さない。ヒーローの思いこみにツッコむ一言にする。どの場面も3〜5通りから選ぶ。

| 場面 | 一言の例 |
|---|---|
| 波の始めの決めつけ | 「暗いってだけで!?」「その決め方、雑すぎ!」 |
| ルールに当てはまる市民に殴りかかる | 「おばあちゃんだよ!?」「帽子かぶってるだけ!」 |
| ルールに当てはまらないワルを素通り | 「どう見てもナイフ持ってる!」「なんで今スルーした!?」 |
| ルールを言い直した | 「また変えた!?」「さっきと違うじゃん!」 |
| 待てで市民を守った | 「セーフ!」「あぶなかった…」 |
| 市民を殴ってしまった | 「見れば分かるって言ったよね!?」 |
| 待ても行けも押さない時間が続く | 「…押して?」「ねえ、見てる?」「もう知らない」(だんだんあきらめていく) |

## ゆっくりモード

一時停止のメニューの「ゆっくりモード」がオンなら、次を1.5倍にする。波の長さ(90秒)は変えない(そのぶん人数が減る)。

- 人と人の間
- マークの長さ(マークの間のヒーローの速さを下げる)
- 悪さのワルが逃げるまで、ギャングが車に乗るまでと車が走る時間、UFOの吸い上げ

波3のルールの言い直しはしない。取れる称号は変わらない(人数が減ったぶん、称号の数字を下げることはしない)。

## 数え方

今の数字をそのまま使う(悪党を倒した、市民のけが、逃がした、被害額)。仕分けがないので「仕分け正解」は出さず、代わりに次を足す。

| 数字 | 数え方 |
|---|---|
| 待てで守った | 殴りかかったヒーローを、待てで市民から止めた人数 |
| 行けで決めた | 素通りしたワルに、行けを押して倒した回数(ギャングをまとめて吹き飛ばしても、UFOを落としても1回) |
| ヒーローの決めつけの当たり | ヒーローのルール通りの動きが正しかった人数と、全部の人数(「当たり15/41人」) |

## 結果画面

ステージ1から3と同じ画面で、次を変える。

- 称号は、フリープレイの称号とステージの称号の両方から、上から順に調べる(下の「称号」)
- 数字の窓は、待てで守った、行けで決めた、市民のけが、逃がした、被害額の順。いちばん下に小さく「ヒーローの決めつけの当たり」
- いちばんひどい場面の候補に、「素通りのヒーローがワルに笑顔で手を振った瞬間」(文は「ナイフ男に笑顔で手を振った!」など)を、いちばん最後の候補として足す(ボスがいないため)
- 「もう一回」はフリープレイをもう一度。「タイトルへ」はタイトルへ
- 共有カードの右上のステージ名は「フリープレイ」

## 称号

フリープレイだけで取れる称号を3つ足して、全部で20個にする。

| 称号 | 条件 | ヒント(称号の一覧) | 勝利ポーズ |
|---|---|---|---|
| ヒーローのお守り役 | ヒーローがなぐった市民とワルにやられた市民が0で、逃がしたワルが0(まきぞえは数えない) | フリープレイで、だれも傷つけず、だれも逃がさない | 決めポーズ |
| ヒーローの通訳 | 待てで10人以上守り、行けで10回以上決めた(チャンスは13ずつ) | フリープレイで、待ても行けも10回ずつ決める | 腕組みでドヤ顔 |
| なすがまま | 効いた待てと行けが0(マークがないときの空押しは数えない) | フリープレイで、ヒーローに全部まかせる | 頭をかいて照れ笑い |

- 順番は、ヒーローのお守り役を「完全無欠のヒーロー」のすぐあと、なすがままを「市民の天敵」のすぐ前、ヒーローの通訳を「待ての達人」のすぐ前にする
- まきぞえを数えないのは、完全無欠と同じ理由(技の当たり方しだいの運なので)
- フリープレイでは、ステージだけの称号(ボスの親友、連打の申し子、一網打尽、ギャングの運転手、宇宙人の案内係、タイムセールの守り神、UFOハンター)は取れない

## 記録

- ステージとは別に、フリープレイの記録を残す:待てで守った数、行けで決めた数、最少負傷、最高被害額のいちばん良いもの
- ステージを選ぶ画面の「フリープレイ▶」のボタンに、いちばん良い記録を小さく出す(「守った12・決めた11」など)

## 音

- フリープレイの曲を1曲足す(速めで、にぎやかな曲。波ごとに少しずつ速くする)
- 決めつけの音を足す(殴りかかるルールは低い「ドン!」、素通りのルールは明るい「ポワン」)
- 行けの空押しの「?」の音(小さく)

## 絵

- 一目で分かるワル3人(ナイフを振りかざしたモヒカン、バンダナで顔を隠したギャング、触角の出た宇宙人)。今のワルの絵をもとに描き足す
- 波3の小物3つ(帽子、サングラス、紙袋)。どの見た目の人にも重ねられる小さな絵と、見た目ごとの付ける場所の表
- ルールの札の絵(拳、手のひら、小物)
- ヒーローの光の形(赤いトゲトゲ、水色の丸)

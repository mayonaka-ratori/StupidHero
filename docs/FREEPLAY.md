# フリープレイ仕様書

仕分けのないモード。ヒーローが見た目だけでルールを決めつけ、その通りに殴ったり素通りしたりするので、プレイヤーは待てと行けだけで直す。ステージ1から3の結果発表の決まり(`docs/SPEC.md`、`docs/STAGE2.md`、`docs/STAGE3.md`)を土台にして、ここに書いたことだけを足したり変えたりしている。

作る前に、5つの人物(通勤電車で遊ぶ会社員、やりこみ勢、笑える場面を共有する人、ゲームデザイナー、子どもと60代の人)になりきった検討を2回して、その意見を入れた。この仕様書は、作ったものに合わせて書き直してある。数字は遊びながら直す(いちばん下の「遊んで直す数字」)。

数字の元は`src/logic/freeplay.ts`の`FREE`と`freeTiming`、文は`src/logic/freeContent.ts`、通りの動きは`src/scenes/street/free.ts`にある。食いちがったときはコードが正しいので、こちらを直す。

## ほかのステージとの違い

| | ステージ1〜3 | フリープレイ |
|---|---|---|
| 殴るか決めるのは | プレイヤーの仕分け | ヒーローの決めつけ |
| 見分けやすさ | 手がかりを組み合わせないと分からない | ワルか市民かは一目で分かる |
| 読むもの | その人がワルか市民か | ヒーローがその人に何をするか、それが合っているか |
| プレイヤーの仕事 | 仕分け、待て、行け | 待てと行けだけ |
| まちがいの原因 | プレイヤーの仕分け | ヒーローの思いこみ |
| オペレーター | 仕分けを手伝う | ヒーローの思いこみにツッコむ |
| 終わり方 | 波3回とボス戦 | 山札の人(27場面)が全員通ったら終わり。ボスなし |
| 記録 | 最多撃破など | クリアまでの時間 |
| 答え合わせ | 波ごとにある | ない |
| 早送り | ある | ない |

仕分けという「ヒーローに教える手間」がないので、「ヒーローが勝手に決めて、勝手にまちがえる」ところだけが残る。Stupid Heroらしさがいちばん出るモードにする。

## 決まったこと

| 項目 | 決定 |
|---|---|
| 形 | 波3回。波の始めに、ヒーローが見た目だけでルールを決めつける。ルールは画面の左上の札に出るので、プレイヤーはヒーローが何をするかを先に読んで構える |
| 終わり方 | 時計で切らない。山札の人が全員通り、悪さがみな終わったら波が終わる。うまく遊んで約100秒 |
| 記録 | クリアまでの時間。逃がしたワルと市民のけが1人につき3秒を足す |
| 舞台と人 | 開いているステージの人をまぜる。背景は波ごとに、開いているステージの背景を1つずつ使う |
| 開き方 | 路地裏のボスを一度倒すと開く |
| ギャングとUFO | ギャングの仲間呼びとUFOは、フリープレイでもそのまま使う |
| 行けの空押し | マークがないときに押すと1.0秒効かなくなり、押し直すたびに数え直す |
| ルールの言い直し | 波3で1回 |
| 称号 | フリープレイだけで取れる称号を3つ足した(全部で20個) |

## 始め方

- ステージを選ぶ画面の下(「◀タイトルへ」の右)に「フリープレイ▶」のボタンを置く。カードは増やさない(カードが多いと、低い画面に入らないため)。キーボードではFキーでも押せる
- 開いていないときは、ボタンを暗くして左に鍵のマークをつける(ステージのカードの鍵と同じ絵)。押すと鍵がガタガタ揺れて、「路地裏をクリアすると遊べる」の吹き出しが出る
- 路地裏のボスを倒した直後にこの画面へ来ると、地下駐車場のカードの鍵がこわれたあとに、ボタンの鍵もこわれて開き、「フリープレイが開いた!」の帯が出る
- 開いていて一度も遊んでいなければ、ボタンの右上に「NEW!」の札を出す(ステージのカードと同じく点滅する)
- 遊んだことがあれば、ボタンの下の段に、いちばん速い時間を小さく出す(「ベスト 1:38」)。ふつうの記録がなく、ゆっくりモードの記録だけあれば「ゆっくりベスト 2:10」
- 初めて遊ぶときだけ、掛け合いを3枚出す(下の「掛け合い」)。見せ始めたら「見た」にするので、途中でとばしても次からは出さない。2回目からはすぐ波1が始まる
- 路地裏しかクリアしていない人(ショッピングモールがまだ開いていない人)には、結果画面で一度だけ「ステージを進めると、出てくる人が増えるよ」と出す(下の「結果画面」)

## 掛け合い

1. オペレーター:「今日は仕分けなし!好きにやらせてみる」
2. ヒーロー:「まかせて!見れば分かるもん!」
3. オペレーター:「…絶対まちがえる。待てと行けで直してね」

## 3回の波

| 波 | ヒーローの決めつけ | 本当は | プレイヤーの仕事 |
|---|---|---|---|
| 1 | 「ここはワルだらけ!」全員に殴りかかる | ほとんど市民 | 市民に待て(待てだけを覚える) |
| 2 | 「ワルはいなさそう!」全員に手を振って素通り | ワルがたくさん | 悪さを始めたワルに行け(行けだけを覚える) |
| 3 | 「風船の人はワル!」のような、小物のルール | ルールと関係なく、ワルと市民がまざる | ルールに当てはまる市民に待て、当てはまらないワルに行け(両方を使い分ける) |

- 決めつけと本当は、わざと逆にする。「ワルだらけ」の波はほとんど市民で、「ワルはいない」の波はワルだらけ。ヒーローのおバカさが、そのまま笑いと忙しさになる
- 決めつけの理由は、背景の見た目だけのこじつけにする(「暗いからワルだらけ!」「明るいからいい人ばかり!」など)。背景ごとに、みんなワルとみんないい人は3通り、小物のルールは小物ごとに2通り
- 波1と波2の順番は変えない(待てから覚えるほうが分かりやすいため)
- 波1と波2はやさしく、波3で難しくする(下の「波3」)
- 曲は3つの波で同じ曲を使い、波ごとに少しずつ速くする(下の「音」)

### 波の始め

- 「WAVE1」の帯のあと、ヒーローの決めつけ(約1.6秒)と、オペレーターのツッコミ(「暗いってだけで!?」など。約1.8秒)を出す。ヒーローは腕組みでドヤ顔をする。その間はクリアまでの時間を止め、待てと行けのボタンも閉じる。画面をタップすると飛ばせる(中断と音のボタンは除く)
- 決めつけと同時に、左上にルールの札を出す。札は絵とひらがなで、字が読めなくても分かるようにする
  - 波1:拳の絵と「みんなワル」
  - 波2:手のひらの絵と「みんないいひと」
  - 波3:1行目は小物の絵と拳で「ふうせん=ワル」、2行目は手のひらで「ほか=いいひと」
- 札の下に、波の番号とクリアまでの時間を小さく出す(「WAVE1 0:12」。足した秒数も入れる。足したときは横に「+3」が小さく飛ぶ)
- ヒーローのまわりの光は、殴りかかる相手に向かうときは赤いトゲトゲの形、素通りする相手に向かうときは水色の丸い形にする(色だけで見分けないように)。「光と揺れを弱くする」がオンなら、点滅させずに、同じ形のふち取りにする

### 波3

波3は、ルールを先に読んだ人が得をするように作る。ワルか市民かは一目で分かるので、ルールを読まずにマークだけ見ても解けないようにする。

- 小物は3つ。どれも今の人の絵にない、大きく目立つものにする(今の絵には、警備員とダンスの学生の帽子、モヒカンのサングラス、買い物袋の女性とおじさんの袋がもともと付いているので、それとまぎれないように)

| 小物 | 札の文 | 付ける場所 | 色 |
|---|---|---|---|
| 風船 | ふうせん | 頭の上の後ろ寄りに浮かぶ(ひもで手前の手につながる) | 黄色 |
| とんがり帽子 | ぼうし | 頭(モヒカンの髪と宇宙人の触角は帽子を突き抜けて見える) | 濃い緑 |
| 大きな紙袋 | かみぶくろ | 手前の手に持つ(袋は11×11ドット。買い物袋の女性とおじさんには付けない) | 茶色 |

- 小物の色は、赤、水色、赤紫、黄緑を使わない(ヒーローの光、ステージ2の塗り替えの色、宇宙人のくずれの色とまぎれないように)
- 地下駐車場の市民の小物(腕章、タオルなど)は、オレンジか紫に塗る(風船の黄色とまぎれないように)
- 小物は人の絵に重ねる別の絵にし、見た目ごとに付ける場所の表を作った(`docs/ART_SPEC.md`の「フリープレイ」)。ワルの目印(ナイフ、バンダナ、バット、触角)は隠さない
- 人が驚いたコマの間は、手の位置が変わるので小物を隠す。人が吹っ飛ぶと小物は手から離れ、風船は空へ飛んでいき、帽子と紙袋は地面に落ちて5秒で消える
- ヒーローは3つのうち1つを選んで「〇〇の人はワル!」と決めつける。当てはまる人には全員殴りかかり、当てはまらない人は全員素通りする。殴りかかるときの吹き出しの左に、小物の絵を出す(「〇〇だからワル!」)
- プレイヤーは次の4通りを見分ける

| | ルールに当てはまる(殴りかかる) | 当てはまらない(素通りする) |
|---|---|---|
| 本当は市民 | 待てで止める | 何もしない |
| 本当はワル | 何もしない(ヒーローが正しい) | 悪さを始めたら行け |

- 波3だけ難しくする
  - マークのゆっくり(0.6倍)をやめ、ため(殴りかかる前に構える時間)を1.08秒から0.8秒にする。マークが出てから技が出るまでは、波1と波2が約1.4秒、波3が約1.0秒になる。先にルールと小物を読んで構えた人だけが間に合う
  - 素通りしたワルが悪さをしている間も、ヒーローは歩き続ける。次の人のマークと行けのマークが重なる場面ができる
    - 歩き続けるのは、モヒカンの悪さ(ナイフで脅す)のときだけ。ギャングの集合とUFOは、ほかのステージと同じくヒーローが待つ(カメラがそちらを向くため)。波1と波2では、モヒカンの悪さのときもヒーローは待つ
    - 行けのマークが2つ同時に出ていたら、行けは先に出たほうに効く
  - 人と人の間は96ドット(悪さの相手が72ドット先に立つので、それと重ならないように)
- ルールの言い直し:波3の前の半分が通ったあと(ふつうは6人目のあと)に1回、ヒーローがルールを言い直す(「やっぱりやめた!帽子の人がワル!」など)。オペレーターは「また変えた!?」などとツッコむ。言い直す瞬間は時計を1.5秒止め、札をくるっと返して変え、ふちを何回か光らせる(「光と揺れを弱くする」がオンなら、点滅させずに一度だけ白くする)。音はドン。ゆっくりモードでも言い直す(時計は3秒止める)
  - 止めている間は、ワルの悪さの時計(モヒカンが逃げるまで、ギャング、UFO)も止め、待てと行けのボタンも閉じる

## 人

- 開いているステージの人をまぜて出す。まだ開いていないステージの人は出さない(ネタばれしないように)。先へ進むほど、にぎやかになる
- ワルは一目で分かる見た目にする。ステージ1から3の手がかりを丸出しにした絵

| ステージ | 一目で分かるワル | 市民 |
|---|---|---|
| 路地裏 | ナイフを頭の上に振りかざしたモヒカン | パーカーの男、スーツの男、買い物袋の女性、おばあさん |
| 地下駐車場 | 顔をバンダナで隠して金属バットを持ったギャング | 警備員、整備士、派手な若者、会社員の女性 |
| ショッピングモール | 頭から触角が出て、肌が緑の宇宙人 | 着ぐるみのバイト、寝不足の店員、ロボットダンスの学生、買い物客のおじさん |

- 人の並べ方は今のステージと同じで、ヒーローが右へ進む。人と人の間は、波1と波2が104ドット(今と同じ)、波3が96ドット
- 毎回、同じ数のチャンスが来るように、山札のように配る(記録が並び方の運で決まらないように)。「行けのチャンス」は人数ではなく、行けを押す場面の数で数える(ギャングの組は1場面)

| 波 | 場面 | 待てのチャンス(殴りかかられる市民) | 行けのチャンス(素通りされるワル) | ヒーローが正しい人 |
|---|---|---|---|---|
| 1 | 8 | 6 | 0 | ワル2 |
| 2 | 7 | 0 | 5 | 市民2 |
| 3 | 12 | 3 | 3 | 6(殴られるワル3、素通りされる市民3) |
| 合計 | 27 | 9 | 8 | 10 |

- 表の数は場面の数。ギャングの組は2人で1場面なので、組が出ると人数は1人ずつ増える(27〜29人)。「ヒーローだけなら10/27人」も場面で数える
- 波3の12場面は、言い直しの前と後の半分ずつに分け、4通り(待て、行け、殴られるワル、素通りされる市民)をどちらの半分にも1つか2つずつ配る。言い直すのは前の半分が通ったあと(ふつうは6人目、ギャングの組が前の半分にいれば7人目)
- 波3の小物は、ルールに当てはまる人が持つ。当てはまらない人は、ほかの小物を持つか、何も持たない。どちらの半分にも、何も持たない人が1人はいる
- 言い直しのあとの半分には、前のルールの小物を持った、ルールに当てはまらない人を1人入れる(札が変わったのを見ないとまちがえるように)
- 紙袋のルールに当てはまる市民は、紙袋を持てる見た目から選ぶ(買い物袋の女性とおじさんは選ばない)
- おばあさんは、波1か波3の待てのチャンスに1人だけ入れる(「おばあちゃんに全力パンチ!」が起きるように)
- ギャングは、フリープレイでは2人の組だけにし、1つの波に1組まで(集合から車で逃げるまでがいちばん長く止まる場面なので)。組は行けのチャンス(素通りされる役)にだけ出す(殴られる役だと、1組で2人ぶんの当たりになるため)。組の2人は並びの中でばらばらに置き、先に来た1人が口笛を吹く
- どのワルが出るかは、開いているステージで決める(記録が運で変わらないように)
  - モヒカンはいつも出る
  - 開いていれば、波2にはギャング1組と宇宙人1人を必ず入れ、残りはモヒカンにする
  - 波3の行けのチャンスには、ギャングか宇宙人のどちらか1つだけを入れ、ほかはモヒカンにする(歩き続ける場面を残すため)
  - 殴られるワルは、モヒカンと宇宙人から偏らないように選ぶ
- 市民は、開いているステージの市民から、使った回数の少ない見た目を選ぶ
- 波3では、素通りされるワルどうしを隣に並べない(次の人のマークと行けのマークが重なりすぎないように)
- ギャングの集合とUFOは同時に出さない。行けのチャンスの並びで、ギャングと宇宙人を続けて置かない。ヒーローはどちらも終わるまで待つ
- 通りがかりの市民は、悪さの相手だけを置く(素通りされるモヒカンの72ドット先と、素通りされる宇宙人のUFOが下りてくる所に1人ずつ)。ほかには置かない(巻きぞえで、記録が並び方の運で決まらないように)。悪さの相手の見た目も、開いているステージの市民から選ぶ
- 背景は、開いているステージを混ぜて波ごとに1つずつ使う。開いているステージが3つより少なければ、前の波と違うものからもう一度選ぶ(路地裏だけなら3つとも路地裏)。置く物(壊れる物)は、その背景のステージの決め方で置く

## 待てと行け

今の決まり(`docs/SPEC.md`の「待てと行け」)のまま使う。違うのは次の所だけ。

- 待てのマークは、ヒーローが殴りかかる相手全員に出る(ワルにも出る。見た目で分かるので、押さないのが正解)
- **ギリギリセーフ**:市民への待てを、ためのいちばん最後の2割で押すと「ギリギリセーフ」になる(いちばんひどい場面の候補。下の「結果画面」)
- **ワルに待てを押したときの取り返し**:待てで止めたワルは、すぐ悪さを始めて行けのマークが出る(ヒーローは「ほら、やっぱりワルじゃん!」)。モヒカンはナイフで脅し、宇宙人はUFOを呼ぶ。行けで倒せば「逃がした」に数えない。「待てで止めた相手をあとで行けで殴れない」の例外で、フリープレイだけの決まり
- 行けのマークは、素通りしたワルが悪さを始めたときに出る
- ワルの悪さ
  - モヒカンは「ナイフで脅す」(けがはさせない。行けが間に合えば、だれも傷つかない)。相手の所へ走っていってナイフを突きつける。行けを押さずに3秒たつと、財布を奪って逃げ、そのとき市民のけが(ワルにやられた)になる
  - ギャングは、口笛で仲間を呼んで集まる(行けでまとめて吹き飛ばす。3秒で車に乗って逃げる)。ワゴンは止めておかず、どの背景でも、口笛のあと画面の右から走ってきて、集まる場所の先に止まる。車が走り出すと、ヒーローは笑顔で手を振って見送る
  - 宇宙人は、UFOを呼んで悪さの相手の市民をさらう(行けでUFOを落とす)
- 行けを押したとき、ヒーローが歩いているか待っていて、相手が前にいれば、走って殴りに行き、殴ったあとに続きを歩く。そうでなければ(待てのマークの最中、ほかの動きの最中、相手が後ろにいるとき)、その場から光の拳を飛ばして倒す。待てのマークの最中なら、ためは続く
- 本性ちらりは出さない(見た目で分かるので要らない)。ヒーローの一言は、ルールに合わせたものにする(下の「ヒーロー」)
- **空押し**:マークがないときに行けを押すと、ヒーローが「?」と振り向き(約0.3秒)、1.0秒だけ行けが効かない。その間に押し直すと、そこから1.0秒数え直す。連打すると一度も効かず、見て押す人は困らない。待ても同じで、ヒーローは「?」と少し(約0.45秒)立ち止まる。振り向くのは、ヒーローが歩いているときと待っているときだけ。効かない間は、そのボタンを暗くする。フリープレイだけの決まり
- 待てや行けのマークが出ている間は、そのボタンがゆっくり明るくなったり暗くなったりする
- マークの長さとゆっくり(0.6倍)は、波1と波2は今のまま。波3は上の「波3」の通り短くする
- 早送りは使えない(ボタンも出さない)

## クリアまでの時間

- 波ごとに、決めつけが終わってから、最後の人が通って悪さがみな終わるまでの時間を数え、3つの波を足す。波の始めの決めつけ、言い直しで止めている時間、「WAVE1 CLEAR!」の帯と次の波へ切りかわる間、一時停止の間は数えない
- 待てで止めるのが早いほど、行けを早く押すほど、速く終わる
- 逃がしたワル1人、市民のけが1人につき、3秒を足す(ワルに待てを押すと、殴るより早く次へ進むので、その得を消すため)。市民のけがには、まきぞえとUFOにさらわれた人も入る
- 時間は「1:38」のように分と秒で書く(秒より下は切り捨て)

## ヒーロー

- 波の始めの決めつけは、背景と波ごとに2〜3通りから選ぶ
- 殴りかかるときと素通りするときの一言は、それぞれ見た目ごとに5通り以上から選ぶ。波3で殴りかかるときは、小物ごとに5通り以上(どれも小物の名前が入る)
  - 殴りかかる:「フードがあやしい!」「その袋、あやしい!」など
  - 素通り:「いい笑顔!」「そのバット、野球だよね!」など
- 殴りかかるときの一言は、マークが出ている間ずっと出しておく
- 市民を殴っても謝らない。腕組みでドヤ顔をして「でもルール通りだし!」と言いはる。まきぞえだけのときは、ほかのステージと同じく「やっちまったー」から「まあいいか」
- 素通りしたモヒカンが悪さを始めると「あれっ!?いい人だと思ったのに!」などと驚く
- 同じ種類の一言では、直前と同じ文を選ばない(ヒーローとオペレーターのどちらかが直前に言った文も避ける)

## オペレーター

仕分けていないので、「…ワルにしたの、私だけど」のような、自分の仕分けを責める一言は出さない。ヒーローの思いこみにツッコむ一言にする。ステージの流れで出る一言(ギャングやUFOの一言など)も出さない。

- 波の始めの決めつけと、言い直しへのツッコミは、毎回言う
- そのほかの場面は、毎回は言わない
  - 1つの波で4回まで
  - その回で初めて起きた場面は、必ず言う
  - 2回目からは4割の割合で言う。前の一言から2.5秒たっていなければ言わない
- 同じ場面の回数で言い方を変える。1回目、2回目から、5回目から(押さない時間は4回目から)の3段で、だんだんあきれたり慣れたりする(1回目「その人、市民!待てで止めて!」、5回目から「もうわざとでしょ」)
- その人や小物に合った一言があれば、半分くらいの割合でまぜる(おばあさん、小物の名前、一目で分かるワルごと)
- その回で初めて行けのマークが出たときは、行けの使い方を短く言う(「悪さを始めた!行けで追いかけて!」)

| 場面 | いつ | 一言の例 |
|---|---|---|
| 波の始めの決めつけ | 決めつけのあと、毎回 | 「暗いってだけで!?」「その決め方、雑すぎ!」 |
| ルールに当てはまる市民に殴りかかる | 待てのマークが出たとき | 「その人、市民!待てで止めて!」「おばあちゃんだよ!?」「風船持ってるだけ!」 |
| ルールに当てはまらないワルを素通り | 手を振ったとき | 「どう見てもワルだよ!?」「どう見てもナイフ持ってる!」 |
| ルールを言い直した | 言い直すとき、毎回 | 「また変えた!?」「さっきと違うじゃん!」 |
| 待てで市民を守った | 待てが効いたとき | 「セーフ!」「あぶなかった…」 |
| 市民を殴ってしまった | 待てを押さずに殴ったとき | 「見れば分かるって言ったよね!?」「よりによっておばあちゃん!」 |
| 行けで決めた | 行けが効いたとき | 「ナイス行け!」「いいね!決まった!」 |
| 取り返した | ワルに待てを押したあと、行けで倒したとき | 「取り返した!セーフ!」 |
| 逃がした | ワルが逃げたとき | 「逃げられた…」「あーあ、逃げてった」 |
| 押さない時間が続く | 押すべきマークを2回続けて逃したとき(市民を殴った、逃がした)、その場面の一言の代わりに | 「…押して?」「ねえ、見てる?」「もう知らない」(だんだんあきらめていく) |

- 押さない時間の一言は、押すべきマークを逃したときだけ数える。ワルの悪さを待っている間など、押さないのが正しいときは言わない。待てや行けが効いたら数え直す

## ゆっくりモード

一時停止のメニューの「ゆっくりモード」がオンなら、次を1.5倍にする。人数とチャンスの数は変えない(山札で終わるので、そのぶん長く遊ぶ)。

- 人と人の間
- マークの長さ(ためを1.5倍にし、マークの間のヒーローの速さも下げる。波3も1.5倍。マークから技までは、波1と波2が約2.0秒、波3が約1.5秒になる)
- 悪さのモヒカンが逃げるまで、ギャングが車に乗るまでと車が走る時間、UFOの吸い上げ
- ルールの言い直しで止める時間(1.5秒を3秒に)

途中でオンにしても、そこから長くなる。一度でもオンにした回は、ゆっくりモードの記録にする。取れる称号は変わらない。

## 数え方

今の数字をそのまま使う(悪党を倒した、市民のけが、逃がした、被害額)。仕分けがないので「仕分け正解」は出さず、代わりに次を足す。

| 数字 | 数え方 |
|---|---|
| クリアまでの時間 | 上の「クリアまでの時間」 |
| 待てで守った | 殴りかかったヒーローを、待てで市民から止めた人数(9人まで) |
| 行けで決めた | 行けを押してワルを倒した場面の数(ギャングをまとめて吹き飛ばしても、車ごと止めても、UFOを落としても1回。8回まで。ワルに待てを押したあとの取り返しは数えない) |
| 空押し | マークがないときに押した回数(効かない間に押し直しても数える) |
| ヒーローの決めつけの当たり | ヒーローだけならどれだけ当たっていたか(いつも10/27)と、プレイヤーが直したあとの数を並べる(「ヒーローだけなら10/27人、あなたが直して25/27人」)。直したあとは、ヒーローが殴った市民と、逃げきったワルの場面(ギャングの組は1つ)を除いた場面の数 |

- ワルに待てを押しても、すぐには「逃がした」に数えない。そのワルが逃げきったときに数える
- 財布を奪って逃げたモヒカンは、「逃がした」と「市民のけが(ワルにやられた)」の両方に数える。相手がもう倒れていたときは「逃がした」だけ
- 称号のために、効いた待てと効いた行けの数(取り返しも入れる)も数える

- 称号は、フリープレイの称号から先に調べる(下の「称号」)

### 共有

- 共有の文の1行目は、ルールと場面をつなげる(「『風船の人はワル!』でおばあちゃんに全力パンチ!」)。ルールは、その場面が起きたときのルール(「みんなワル!」「みんないい人!」「〇〇の人はワル!」)。場面は、ステージの強い場面(おばあさんを殴った、市民に必殺技、市民を殴った、さらわれた、大きな物が壊れた)があればその文、なければ上の2つの場面の文。どちらもなければ称号(称号「なすがまま」。ルールはつけない)
- 共有カードの右上のステージ名は「フリープレイ」。背景は波3の背景のステージ
- 写真の右上の角の上(オペレーターの顔の左)に、その場面のときのルールの札を小さく出す(絵とひらがな)。写真の中に置くと、人の顔が見出しに隠れるため
- カードの数字は、結果画面の窓と同じ並びで4行に入れる

```
クリアまでの時間              1:38(2段ぶんの大きさ)
待てで守った 9/9人
行けで決めた 8/8回        市民のけが 0人
```

- 左と右がぶつかるとき(けがが2けたなど)は、左の数字の「/9」「/8」を省く
- 「ヒーローだけなら…」の1行はカードに入れない(入れると写真を低くするしかなく、人の顔が見出しに隠れるため)
- ゆっくりモードで遊んだ回は、いちばん下の「#StupidHero」の左に「ゆっくり」の印を出す

## 記録

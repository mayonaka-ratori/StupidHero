# Stupid Hero 仕様書(最初の版)

この仕様書はステージ1(路地裏)と、全体の決まりです。ステージ2(地下駐車場)で足したり変えたりしたことは`docs/STAGE2.md`にあります。

敵と味方の区別がつかないヒーローに、プレイヤーが「こいつはワル、こいつは市民」と教えて、街を悪党とヒーローの両方から守るゲーム。

画面の向きのモックは`mocks/orientation.html`にあります。採用したのは「B 縦持ち」です。

## 決まったこと

| 項目 | 決定 |

| 遊ぶ場所 | スマホのブラウザ。URLを開くだけで遊べる |
| 画面の向き | 縦持ち。上がゲーム画面、下がオペレーターとボタン |
| 見た目 | メガドライブくらいのドット絵。横スクロールのベルトアクション |
| プレイヤーの立場 | ヒーローの相棒のオペレーター。画面には右上のカットインでだけ出る |
| ヒーロー | 女の子。いつでも元気で大げさ。ミスしてもへこまない |
| オペレーター | 女の子。ヒーローの幼なじみ。ため口でツッコミを入れ、ときどき一緒に盛り上がる |
| 名前 | 2人の名前は作る人があとで決める。決まるまでは「ヒーロー」「オペレーター」と書く |
| 最初に作る範囲 | 路地裏ステージ1つだけ。波3回と最後のボス戦、結果画面、SNS共有まで |

## ゲームの流れ

1. タイトル画面(「タップしてスタート」。ここで音を鳴らし始める)
2. ステージ前の掛け合い(ヒーローとオペレーターの短い会話。遊び方もここで伝える)
3. 波1:仕分け → 結果発表
4. 波2:仕分け → 結果発表
5. 波3:仕分け(ボスが紛れている) → 結果発表 → ボス戦
6. 結果画面(称号、勝利ポーズ、数字)
7. SNSに共有、または「もう一回」

1ステージは3〜4分、全部で16人(ボスを含む)。テンポは早めにする。

## 仕分け

- 人が1人ずつ画面の真ん中に出てくる。左にスワイプでワル、右にスワイプで市民。下の◀ワル/市民▶ボタンを押してもいい
- 時間制限は波ごとにまとめてかける
- 1つの波のワルは2〜3人で、毎回ランダムに決まる

| 波 | 人数 | 制限時間 | メモ |
|---|---|---|---|
| 1 | 5人 | 20秒 | 練習の波。一目でワルと分かる人を必ず1人入れる |
| 2 | 5人 | 15秒 | |
| 3 | 5人とボス1人 | 18秒 | |

- 時間切れで仕分けていない人は、ヒーローが気まぐれで決める(半々)
- 残り5秒になったら、画面の端を赤く点滅させる

### 見分ける手がかり

仕分け中は次の4つが出る。

1. **見た目**:ドット絵の細かいところ。ナイフの柄が見える、女物のバッグを持っている、など
2. **動き**:仕分けの画面でも少し動く。キョロキョロする、腕時計を見る、など。1.5秒以内の動きをくり返す
3. **プロフィール**:名前、年齢、短い一文。嘘は書かないが、どちらとも取れる
4. **オペレーターの一言**:右上のカットインでつぶやく。嘘はつかないが、どちらとも取れる言い方をする

### 同じ見た目の市民とワル

服装だけで見分けられないように、同じ見た目の市民とワルを組にして用意する。違いは付け足しの小物や動きだけにする。

| 見た目 | 市民のとき | ワルのとき | オペレーターの一言 |
|---|---|---|---|
| パーカーの男 | ポケットに財布 | ポケットからナイフの柄 | 「ポケットがふくらんでる…」 |
| スーツの男 | 腕時計を見てあせる | 女物のバッグを抱えている | 「さっきからずっと走ってる」 |
| 買い物袋の女性 | 袋から米袋がのぞく | 袋から財布や腕時計がのぞく | 「袋がやけに重そう」 |

ほかに、一目でワルと分かるモヒカンのチンピラと、市民だけのおばあさんがいる。

1つの手がかりだけでは決められず、2つ3つ合わせると分かる、くらいの難しさを目指す。

## 結果発表

仕分けが終わると、ヒーローが路地裏を右へ進みながら、仕分け通りに動く。

- 仕分けでワルにした人:ヒーローが飛びかかって殴る
- 仕分けで市民にした人:ヒーローは笑顔で手を振って素通りする
- 本当はワルなのに市民にしてしまった人:ヒーローが素通りしたあと、ヒーローを追い抜いて前へ走り、画面の中で悪さを始める(ひったくり、市民を突き飛ばす)
- 本当は市民なのにワルにしてしまった人:ヒーローが全力で殴る

### 待て と 行け

画面下の2つの大きなボタン。回数は自由で、押しても何も減らない(結果オーライ)。

- **待て**:ヒーローが殴りかかる前に押すと、攻撃を中止する。ヒーローは急ブレーキして「了解!」と敬礼し、次へ進む
- **行け**:悪さを始めたワルにヒーローを向かわせ、追い打ちさせる

決まり:

- マークは、ヒーローが殴りに行く相手全員と、悪さを始めたワルに出る。相手を見ても本当のことは分からない
- マークは、ヒーローが相手の48ドット手前に来たときに出て、殴る瞬間に消える。その間は動きが0.6倍にゆっくりになる。合わせて約1.5秒
- 悪さを始めたワルは、行けを押さなければ3秒で画面の右から逃げる。逃げたワルは「逃がした」に数える
- マークがないときに押しても何も起きない
- マークが2人に出ているときは、ヒーローに近い方が対象になる
- 待てで止めた相手を、あとで行けで殴ることはできない
- ボスには待ては効かない

### ヒーローの動き

ヒーローの動きは、攻撃に限らず全部ハデにする。力の加減ができず、何をしても大げさで、周りまで巻きこむのがStupid Heroらしさ。

攻撃は殴るたびにランダムで選ぶ。最初の版は次の4つ。

| 攻撃 | どんな技か | 周りへの巻きぞえ |
|---|---|---|
| 光の突撃 | 全身に光をまとって相手に突っこむ | 通り道の物を壊す |
| 光のパンチ | パンチすると拳の形の光が飛んでいく | 光は相手を突き抜けて、その先の物に当たるまで飛ぶ |
| 踏みつぶし | 高く跳んで、上から踏みつぶす | 着地の衝撃波が左右に広がり、近くの物を壊す |
| 必殺技(まれに出る) | 画面の端まで届く太い光線 | 光線の通り道にある物を全部壊す |

- 選ばれる割合は、光の突撃30%、光のパンチ35%、踏みつぶし30%、必殺技5%
- 光のパンチ、衝撃波、光線は、先にいる市民に当たることがある(巻きぞえ)。当たった市民は市民負傷に数える
- 巻きぞえで市民を傷つけたときも「やっちまったー!」→「まあいいか!」が出る

攻撃以外の動きもハデにする。

| 動き | ハデにするところ |
|---|---|
| 待機 | 体のまわりに光がゆらめく |
| 走る | 光の尾を引く |
| 素通り | 手を振ると、キラキラが飛び散る |
| 待てで止まる | 急ブレーキで地面から火花が散り、足あとが焦げる |
| やっちまったー | 背景に「ガーン」の稲妻が走る |
| まあいいか | 後ろから光が差して「キラーン」 |
| 勝利ポーズ | 背中で爆発が起きる(特撮ヒーローのように) |

光の見せ方は、メガドライブと同じく半透明は使わない。1コマおきに点滅させて、透けているように見せる。

アッパー、飛び蹴り、投げ、ヒップアタックは次の版で足す(これも全部ハデにする)。

市民を殴ってしまったとき:

1. 殴ったあと「やっちまったー!」と頭を抱える
2. 一瞬で立ち直って「まあいいか!」
3. 何事もなかったように次へ進む

オペレーターが「まあいいか、じゃない!」とツッコむ。テンポを落とさないように、同じステージの2回目からは短い版にする。

### 街が壊れる

路地裏にはゴミ箱、自販機、看板、窓、止めてある車などがある。ヒーローの攻撃やワルの悪さで壊れると、被害額が増える。額は大げさでいい。

| 物 | 被害額 |
|---|---|
| ゴミ箱 | ¥3万 |
| 窓 | ¥8万 |
| 看板 | ¥15万 |
| 自販機 | ¥80万 |
| 止めてある車 | ¥300万 |

ワルの悪さ(ひったくりなど)も1回¥20万として被害額に足す。

## ボス

- 波3の仕分けの中に、市民に化けたボスが1人いる。化けた姿は毎回変わる(会社員、おばあさん、買い物袋の女性の3つから選ぶ)
- 化けた姿は市民とほぼ同じだが、どこか1か所だけおかしい(少し大きい、腕に入れ墨がのぞく、など)
- 結果発表でヒーローがボスの前に来たとき:
  - ワルに仕分けていた場合:ヒーローが殴りかかり、ボスが正体を現してボス戦へ
  - 市民に仕分けていた場合:ヒーローが素通りしたあと、ボスが正体を現して周りを壊しながら暴れる(被害額に¥1,000万を足す)。そのあとボス戦へ
- 路地裏のボスは、路地裏を仕切っている大柄なワルのボス

### ボス戦

- **行けボタンの連打**。連打の速さでヒーローのラッシュが速くなる
- ボスの体力は連打40回分
- 1秒に10回を超えた分は数えない
- 手が止まっている間はボスが暴れて、1秒ごとに被害額が¥50万増える
- 負けはない。ボスの体力は時間でも少しずつ減り、どんなに遅くても15秒で倒せる
- ボス戦にかかった秒数を記録する

## SNS共有

- 結果画面の「共有する」ボタンで、結果カードの画像と文とURLを流す
- 画像は縦4:5(1080×1350)。ゲームの中で216×270のドット絵で作り、5倍に拡大する
- カードの中身:上に称号とヒーローの勝利ポーズ、真ん中にいちばんひどかった場面、下に数字、被害額のたとえ、称号の数
- 画像は結果画面が出た時点で作っておく(ボタンを押してから作ると、iPhoneで共有メニューが開かないことがある)
- スマホの共有メニューが使えるときは画像つきで共有する
- 使えないときや失敗したときは、画像を大きく出して「長押しで写真に保存」と表示し、その下に「Xに投稿」ボタンを置く
- URLだけで共有されたときのために、見栄えのする共有用の画像を1枚用意してページに設定する
- 文の例:

```
【Stupid Hero】路地裏ステージ
悪党8人撃破/市民3人負傷
被害額¥2,400万(自販機30台分)
称号「歩く解体工事」(3/12)
#StupidHero
https://(ゲームのURL)
```

## 画面(縦持ち)

ゲームの画面は横216×縦384ドット。

- 上(0〜214ドット):ゲーム画面。右上にオペレーターのカットイン
- 下(214ドットから下):数字、オペレーターのセリフ、ボタン
  - 仕分け中:プロフィール、◀ワル、市民▶
  - 結果発表中:待て!、行け!
  - ボス戦:行け!(大きく)

大きさの決め方:

- 横幅216を、画面の実際の画素の数で整数倍に拡大する(CSSの単位で計算すると多くのiPhoneで1倍になってしまうため)
- 整数倍では小さすぎるときは、小数倍も許す
- 縦に余ったぶんは、下の操作部分を伸ばして使う
- 画面下のホームバーのぶん、ボタンを上にずらす
- スマホを横にされたときは「縦にしてね」と出す

## スマホのブラウザで気をつけること

- **スワイプ**:人物の絵の上から始めたときだけ受け付ける。画面の左右の端から始まった動きは無視する(Safariの「戻る」とぶつかるため)
- **連打**:指が触れた瞬間に数える。2本の指で交互に押しても数える。2回タップでの拡大、長押しのメニュー、文字の選択、下に引っぱって再読み込み、を止める
- **音**:iPhoneはタップするまで音が出ず、マナーモードだと鳴らないことが多い。音がなくても遊べるようにし、合図を音だけに頼らない。音のオン/オフボタンを付ける。共有メニューやアプリの切り替えから戻ったら、次のタップで音を再開する
- **画面を離れたとき**:通知やアプリの切り替えで画面が隠れたら、時計とゲームを止める。戻ったら「タップで再開」を出す

## 作り方(技術)

- TypeScriptとPhaser 3で作る。ビルドはVite
- 音はWeb Audioで合成する。FM音源っぽい音色にする。音の出口は1つにまとめる(Phaserの音の仕組みと取り合いにならないようにする)
- 公開はGitHub Pages(サーバーなしで動く)。公開のしかたは`docs/DEVELOP.md`
- 絵は1コマごとの画像を並べた画像ファイル(スプライトシート)で読み込む。最初はコードで作った絵を同じ形式で書き出し、あとでChatGPTの絵と差し替えるだけで済むようにする
- 作る前の確認として、実際のiPhoneとAndroidで、X、LINE、Instagramへの共有を試す

# Stupid Hero 仕様書(最初の版)

敵と味方の区別がつかないヒーローに、プレイヤーが「こいつはワル、こいつは市民」と教えて、街を悪党とヒーローの両方から守るゲーム。

画面の向きのモックは `mocks/orientation.html` にあります。採用したのは「B 縦持ち」です。

## 決まったこと

| 項目 | 決定 |
|---|---|
| 遊ぶ場所 | スマホのブラウザ。URLを開くだけで遊べる |
| 画面の向き | 縦持ち。上がゲーム画面、下がオペレーターとボタン |
| 見た目 | メガドライブくらいのドット絵。横スクロールのベルトアクション |
| プレイヤーの立場 | ヒーローの相棒のオペレーター。画面には右上のカットインでだけ出る |
| ヒーロー | 女の子。いつでも元気で大げさ。ミスしてもへこまない |
| オペレーター | 女の子。ヒーローの幼なじみ。ため口でツッコミを入れ、ときどき一緒に盛り上がる |
| 名前 | 2人とも自分で決める。それまでは仮に「ヒーロー」「オペレーター」と書く |
| 最初に作る範囲 | 路地裏ステージ1つだけ。波3回と最後のボス戦、結果画面、SNS共有まで |
| 絵 | ひとまずコードでドット絵を作る。あとでChatGPTで描いた絵に差し替える(`docs/ART_SPEC.md`) |
| 音 | メガドライブ風のBGMと効果音をブラウザで合成して鳴らす |
| スコアボード | 最初はそのスマホの中の自分の記録だけ。あとで全国ランキングを足す |
| 評価 | 点数やランクは出さず、称号だけ |

## ゲームの流れ

1. タイトル画面
2. ステージ前の掛け合い(ヒーローとオペレーターの短い会話)
3. 波1:仕分け → 結果発表
4. 波2:仕分け → 結果発表
5. 波3:仕分け(ボスが紛れている) → 結果発表 → ボス戦
6. 結果画面(称号、勝利ポーズ、数字)
7. SNSに共有

1ステージは3〜4分、全部で15人くらい。テンポは早めにする。

## 仕分け

- 人が1人ずつ画面の真ん中に出てくる。左にスワイプでワル、右にスワイプで市民。ボタンを押してもいい
- 時間制限は波ごとにまとめてかける

| 波 | 人数 | 制限時間 |
|---|---|---|
| 1 | 5人 | 15秒 |
| 2 | 5人 | 13秒 |
| 3 | 5人とボス1人 | 16秒 |

- 時間切れで仕分けていない人は、ヒーローが気まぐれで決める(半々)

### 見分ける手がかり

仕分け中は次の3つが出る。

1. **見た目**:ドット絵の細かいところ。ナイフの柄が見える、目つきが悪い、など
2. **動き**:仕分けの画面でも少し動く。キョロキョロする、落ちた財布を拾う、など。見逃すと分からない
3. **オペレーターの一言**:右上のカットインでつぶやく。嘘はつかないが、どちらとも取れる言い方をする

オペレーターの一言の例:

| 相手 | 一言 | 本当は |
|---|---|---|
| パーカーの男 | 「ポケットがふくらんでる…」 | 中身は財布(市民)のこともナイフ(ワル)のこともある |
| スーツの男 | 「さっきからずっと走ってる」 | 電車に遅れそうな会社員、またはひったくりの帰り |
| 買い物袋の女性 | 「袋がやけに重そう」 | 特売の米、または盗んだ物 |

1つの手がかりだけでは決められず、2つ3つ合わせると分かる、くらいの難しさを目指す。

## 結果発表

仕分けが終わると、ヒーローが路地裏を右へ進みながら、仕分け通りに動く。ここがハラハラする場面。

- 仕分けでワルにした人:ヒーローが飛びかかって殴る
- 仕分けで市民にした人:ヒーローは笑顔で素通りする
- 本当はワルなのに市民にしてしまった人:ヒーローが通りすぎたあと、ひったくりや市民への攻撃を始める
- 本当は市民なのにワルにしてしまった人:ヒーローが全力で殴る。市民負傷に数えられる

### 待て と 行け

画面下の2つの大きなボタン。回数は自由で、押してもスコアは減らない(結果オーライ)。

- **待て**:ヒーローが殴りかかる前に押すと、攻撃を中止する。市民を守れる
- **行け**:暴れ出した悪党(市民に仕分けてしまったワル)にヒーローを向かわせ、追い打ちさせる

タイミングはゆるめにする。

- ヒーローが相手に向かう少し前から、相手の頭の上にマークが出る
- マークが出ている間は動きが少しゆっくりになる
- だいたい1.5秒くらいの間に押せば間に合う

### ヒーローの動き

攻撃の動きはたくさん用意し、殴るたびにランダムで選ぶ。

- パンチ連打、キック、アッパー、飛び蹴り、投げ、ヒップアタック、必殺技(まれに出る)
- 強い技ほど周りの物も壊しやすい

市民を殴ってしまったとき:

1. 殴ったあと「やっちまったー!」と頭を抱える
2. 一瞬で立ち直って「まあいいか!」
3. 何事もなかったように次へ進む

オペレーターが「まあいいか、じゃない!」とツッコむ。

### 街が壊れる

路地裏にはゴミ箱、自販機、看板、窓、止めてある車などがある。ヒーローの攻撃が当たると壊れて、被害額が増える。大きな数字になるほどSNSでネタになるので、額は大げさでいい(例:自販機1台¥80万)。

## ボス

- 波3の仕分けの中に、市民に化けたボスが1人いる。化けた姿は毎回変わる(会社員、おばあさん、配達員など)
- 化けていても、手がかりのどこかに必ずヒントがある
- 結果発表でヒーローがボスの前に来たとき:
  - ワルに仕分けていた場合:ヒーローが殴りかかり、ボスが正体を現してボス戦へ
  - 市民に仕分けていた場合:ヒーローが素通りしたあと、ボスが正体を現して周りを壊しながら暴れる(被害が大きい)。そのあとボス戦へ
- ボス戦は **行けボタンの連打**。連打の速さでヒーローのラッシュが速くなり、ボスの体力が減る
- 路地裏のボスは、路地裏を仕切っている大柄なワルのボス

## 結果画面

出すもの:

- 悪党撃破数
- 市民負傷数
- 被害額
- 称号
- 勝利ポーズ(称号に合わせて数パターンから選ぶ)

### 称号と勝利ポーズ(案)

| 条件 | 称号 | 勝利ポーズ |
|---|---|---|
| 悪党を全員倒し、市民負傷0、被害額が少ない | 街のほんものヒーロー | 決めポーズ |
| 悪党を全員倒したが、市民負傷も多い | 正義の暴走機関車 | 腕組みでドヤ顔 |
| 被害額がとても大きい | 歩く解体工事 | がれきの上で拳を突き上げる |
| 市民負傷が悪党撃破より多い | 市民の天敵 | 頭をかいて照れ笑い |
| 市民負傷0だが悪党をたくさん逃がした | やさしすぎるヒーロー | 決めポーズ |
| どれにも当てはまらない | まあまあヒーロー | 腕組みでドヤ顔 |

細かい数字は遊びながら決める。

## SNS共有

- 結果画面の「共有する」ボタンで、結果カードの画像と文とURLを流す
- 画像は縦4:5(1080×1350)。ゲームの中で216×270のドット絵で作り、5倍に拡大する
- スマホの共有メニューが使えるときは画像つきで共有する。使えないときは画像を保存し、Xの投稿画面を開く
- 文の例:

```
【Stupid Hero】路地裏ステージ
悪党12人撃破/市民3人負傷/被害額¥2,400万
称号「歩く解体工事」
#StupidHero
https://(ゲームのURL)
```

## 画面(縦持ち)

ゲームの画面は横216×縦384ドット。スマホに合わせて整数倍で拡大し、余ったところは黒か枠の絵で埋める。

- 上(約0〜214ドット):ゲーム画面。右上にオペレーターのカットイン
- 下(約214〜384ドット):数字、オペレーターのセリフ、ボタン
  - 仕分け中:プロフィール、◀ワル、市民▶
  - 結果発表中:待て!、行け!

## 作り方(技術)

- TypeScriptとPhaser 3で作る。ビルドはVite
- 音はWeb Audioで合成する。FM音源っぽい音色にする
- 公開はGitHub PagesかCloudflare Pages(サーバーなしで動く)
- 絵は1コマごとの画像を並べた画像ファイル(スプライトシート)で読み込む。最初はコードで作った絵を同じ形式で書き出し、あとでChatGPTの絵と差し替えるだけで済むようにする

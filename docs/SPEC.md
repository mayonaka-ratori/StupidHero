# Stupid Hero 仕様書

この仕様書はステージ1(路地裏)と、全部のステージに共通する決まりです。ステージ2(地下駐車場)だけで足したり変えたりしたことは`docs/STAGE2.md`、ステージ3(ショッピングモール)だけのことは`docs/STAGE3.md`、仕分けのないフリープレイのことは`docs/FREEPLAY.md`にあります。

敵と味方の区別がつかないヒーローに、プレイヤーが「こいつはワル、こいつは市民」と教えて、街を悪党とヒーローの両方から守るゲーム。

画面の向きのモックは`mocks/orientation.html`にあります。採用したのは「B 縦持ち」です。

## ゲームの流れ

1. タイトル画面(「タップしてスタート」。ここで音を鳴らし始める)
2. ステージを選ぶ画面(下の「ステージを選ぶ画面」)。まだどのステージも遊んだことがない人は、この画面を出さずにすぐ路地裏を始める。フリープレイもここから始める
3. ステージ前の掛け合い(ヒーローとオペレーターの短い会話。仕分けのやり方だけを伝える)
4. 波1:仕分け→結果発表→答え合わせ
5. 波2:仕分け→結果発表→答え合わせ(ショッピングモールは、結果発表のあとにタイムセールラッシュが入る。`docs/STAGE3.md`)
6. 波3:仕分け(ボスが紛れている)→結果発表→ボス戦→答え合わせ
7. 結果画面(称号、勝利ポーズ、数字、いちばんひどい場面)
8. SNSに共有、「もう一回」、称号の一覧

路地裏は1ステージ3〜4分、全部で16人(ボスを含む)。テンポは早めにする。

### タイトル画面

- ロゴ、何をするゲームかの2行(下の「最初の1分」)、「タップしてスタート」を出す
- その下に、集めた称号の数(「称号5/20」。全部のステージとフリープレイを合わせて数える)
- いちばん下に「ホーム画面に追加すると記録が消えにくくなります」(下の「自分の記録」)
- 右上に音のボタン

### ステージを選ぶ画面

- タイトルでタップすると出る。まだどのステージも遊んだことがない人には出さず、すぐ路地裏を始める(開いているのが路地裏だけなので)
- 3つのステージのカードを縦に並べる。カードには背景の絵を小さく切り出して、そのステージの人とボスを立たせる。画面が低くて絵が細くなりすぎるときは、絵を出さずに名前と記録だけのカードにする

| ステージ | 開き方 | 開いていないときの文 |
|---|---|---|
| 1 路地裏 | 最初から選べる | |
| 2 地下駐車場 | 路地裏のボスを一度倒すと開く | 路地裏をクリアすると遊べる |
| 3 ショッピングモール | 地下駐車場のボスを一度倒すと開く | 地下駐車場をクリアすると遊べる |

- 開いていないカードは、絵を暗くして人を黒い影にし、鍵のマークと上の文を出す。タップするとカードが揺れるだけ
- 開いているカードには、そのスマホの中のいちばん良い記録(最多撃破、最少負傷、最高被害額、最速ボス戦)と、そのステージで取れる称号のうちいくつ取ったか(路地裏は12、地下駐車場は13、ショッピングモールは14のうち)を出す。まだ遊んでいなければ「まだ遊んでいない」
- まだ遊んでいないカードには札をつける(路地裏は「ここから!」、ほかは「NEW!」)。初めての人には路地裏のカードを指さす手を出す
- 結果画面で次のステージが開いたあとにこの画面へ来ると、鍵がこわれて開く演出をする
- カードをタップすると、そのステージの掛け合いへ行く。掛け合いを見たか、そのステージを一度遊んだことがあれば、すぐ仕分けへ
- 左下の「◀タイトルへ」でタイトルへ戻る。右上に音のボタン
- 「◀タイトルへ」の右に「フリープレイ▶」のボタンを置く。路地裏のボスを一度倒すまでは暗くして鍵のマークをつけ、押すと「路地裏をクリアすると遊べる」と出る。開いたあとは、いちばん速いクリアまでの時間を小さく出す(`docs/FREEPLAY.md`の「始め方」)

### 最初の1分

初めての人がすぐ遊び始められるように、始まるまでを短くする。

- タイトルのロゴの下に、何をするゲームかを2行で出す(「敵と味方の区別がつかないヒーローに」「ワルと市民を教えて、街を守れ!」)
- 初めての人はステージを選ぶ画面をとばして、タップしたらすぐ路地裏の掛け合いへ行く(上の「ステージを選ぶ画面」)
- 掛け合いは短くする。路地裏は3枚(スワイプのしかた、手がかりの4つ、ヒーローの一言)。待てと行けは、ここでは言わずに、結果発表で初めて使うときに教える。地下駐車場とショッピングモールの掛け合いは、それぞれ5枚で新しい遊び方を教える(`docs/STAGE2.md`、`docs/STAGE3.md`)
- セリフに合わせて、右側の小さな画面でお手本を見せる(スワイプのしかた、手がかり、など)
- 掛け合いは、そのステージで一度だけ出す。見たことはステージごとに記録に残す。見たか、そのステージを一度遊んだら、次からは掛け合いをとばしてすぐ仕分けへ行く(「もう一回」のときも同じ)
- 掛け合いを見せ始めた時点で「見た」にする(途中でとばしても、次からは出さない)
- 掛け合いの画面は、下に大きな「次へ▶」と、その左に小さな「とばす▶▶」を置く(どちらも親指が届くところ)。画面のどこをタップしても次へ進む

## 仕分け

- 人が1人ずつ画面の真ん中に出てくる。左にスワイプでワル、右にスワイプで市民。下の◀ワル/市民▶ボタンを押してもいい
- 時間制限は波ごとにまとめてかける
- 1つの波のワルは2〜3人で、毎回ランダムに決まる

路地裏の波は次の通り。地下駐車場とショッピングモールの波は`docs/STAGE2.md`と`docs/STAGE3.md`の「波と人数」。

| 波 | 人数 | 制限時間 | メモ |
|---|---|---|---|
| 1 | 5人 | 30秒 | 練習の波。一目でワルと分かる人を必ず1人入れる |
| 2 | 5人 | 22秒 | |
| 3 | 5人とボス1人 | 24秒 | |

- 時間は、プロフィールと一言を読み、「持ち物」の窓も見て決められるように、はじめに決めた時間(20秒、15秒、18秒)より長くした
- プロフィールと一言は1文字ずつ出す。出している間は時計を止め、時間の下に「時計ストップ中」の札を出す(読む速さで不利にならないように)
- 一時停止のメニューの「ゆっくりモード」では、制限時間が1.5倍になる。取れる称号は変わらない(下の「一時停止と設定」)
- 時間切れで仕分けていない人は、ヒーローが気まぐれで決める(半々)。答え合わせと結果画面の「仕分け正解」では、自分の仕分けに数えない
- 残り5秒になったら、画面の端を赤く点滅させ、オペレーターが急かす

### 仕分けの画面

- 真ん中にスポットライトの下の人。その右に「持ち物」の窓
- 下の窓に、名前と年齢、プロフィール、細い線の下にオペレーターの小さな顔と一言。読むものは全部この窓にまとめる
- 右上に音と中断のボタン(ほかの画面と同じ位置)
- 一番下に◀ワル、市民▶のボタン

### 見分ける手がかり

仕分け中は次の4つが出る。地下駐車場ではおそろいの小物や仲間の合図、ショッピングモールでは待つと分かる動きのくずれが加わる(`docs/STAGE2.md`、`docs/STAGE3.md`の「手がかり」)。

1. **見た目**:ドット絵の細かいところ。ナイフの柄が見える、女物のバッグを持っている、など。「持ち物」の窓に、手がかりのあたりを3倍にして映す。同じ見た目の人は、市民でもワルでもボスでも同じ場所を映す(映る場所で正体が分からないように)
2. **動き**:仕分けの画面でも少し動く。キョロキョロする、腕時計を見る、など。1.5秒以内の動きをくり返す
3. **プロフィール**:名前、年齢、短い一文。嘘は書かないが、どちらとも取れる。パーカー、スーツ、買い物袋の人には、市民にもワルにも出る一文もまぜる(文だけでは決められない人が出る)
4. **オペレーターの一言**:下の窓でつぶやく。嘘はつかないが、どちらとも取れる言い方をする。顔は文だけで決める(同じ文ならいつも同じ顔)。同じ見た目の市民とワルで、あわてた顔の数をそろえる(顔だけで分からないように)

### 同じ見た目の市民とワル

服装だけで見分けられないように、同じ見た目の市民とワルを組にして用意する。違いは付け足しの小物や動きだけにする。

| 見た目 | 市民のとき | ワルのとき | オペレーターの一言 |
|---|---|---|---|
| パーカーの男 | ポケットに財布 | ポケットからナイフの柄 | 「ポケットがふくらんでる…」 |
| スーツの男 | 腕時計を見てあせる | 女物のバッグを抱えている | 「さっきからずっと走ってる」 |
| 買い物袋の女性 | 袋から米袋がのぞく | 袋から財布や腕時計がのぞく | 「袋がやけに重そう」 |

ほかに、一目でワルと分かるモヒカンのチンピラと、市民だけのおばあさんがいる。

1つの手がかりだけでは決められず、2つ3つ合わせると分かる、くらいの難しさを目指す。

## 結果発表

仕分けが終わると、ヒーローが路地裏を右へ進みながら、仕分け通りに動く。

- 仕分けでワルにした人:ヒーローが飛びかかって殴る
- 仕分けで市民にした人:ヒーローは笑顔で手を振って素通りする
- 本当はワルなのに市民にしてしまった人:ヒーローが素通りしたあと、ヒーローを追い抜いて前へ走り、画面の中で悪さを始める(ひったくり、市民を突き飛ばす)
- 本当は市民なのにワルにしてしまった人:ヒーローが全力で殴る

始まりに「出動!待て・行けの出番」の帯を出す(見ているだけの画面だと思われないように)。

### 早送り

- 右上の丸いボタン(▶▶)で早送りする。時計、動き、アニメがまとめて2倍になる
- 待てと行けのマークが出ている間だけは、ふつうの速さに戻す(考える時間を減らさないため)
- オンとオフは、ページを開いている間は波や回をまたいで覚えておく
- 右上には左から、早送り、音、中断のボタンが並ぶ

### 待てと行け

画面下の2つの大きなボタン。回数は自由で、押しても何も減らない(結果オーライ)。

- **待て**:ヒーローが殴りかかる前に押すと、攻撃を中止する。ヒーローは急ブレーキして「了解!」と敬礼し、次へ進む
- **行け**:悪さを始めたワルにヒーローを向かわせ、追い打ちさせる

使い方は、その回で初めてマークが出たときにオペレーターが教える(待ては「ワルにした人だよ。ちがうと思ったら待て!」、行けは「悪さを始めた!行けで追いかけて!」)。

決まり:

- マークは、ヒーローが殴りに行く相手全員と、悪さを始めたワルに出る。マークからは本当のことは分からない
- マークは、ヒーローが相手の48ドット手前に来たときに出て、殴る瞬間に消える。その間は動きが0.6倍にゆっくりになる。合わせて約1.5秒
- 悪さを始めたワルは、行けを押さなければ3秒で画面の右から逃げる。逃げたワルは「逃がした」に数える
- マークがないときに押しても何も起きない
- マークが2人に出ているときは、ヒーローに近い方が対象になる
- 待てで止めた相手を、あとで行けで殴ることはできない
- 待てで止めた相手が本当はワルだったら、オペレーターが「あ、ワルだったかも…」と小さく気づく(「逃がした」に数える)
- ボスには待ては効かない
- 押せるときは、ボタンをゆっくり明るくしたり戻したりする。強く点滅させると、正しくワルにした人にも待てを押したくなるので、やさしく光らせるだけにする

### 本性ちらりとヒーローの決めつけ

待てのマークが出た瞬間に、次の2つが起きる。

- **本性ちらり**:相手が一瞬だけ正体を見せる。本当はワル(ボスも)なら、くるっと背を向けて何かを隠し「サッ…」。本当は市民なら、小さくおじぎして「ぺこり」。待てを押すかどうかの手がかりになる
- **ヒーローの決めつけ**:ヒーローが見た目から理由をつけて言い切る(「ポケットがふくらんでる!ワルで間違いない!」など)。文は見た目ごとに決め、本当の正体では変えない(文で分からないように)。技を出すまで出しておく

殴ったあとは、相手によって変える。

- 本当のワルだった:ヒーローが「ほらね!顔に書いてあった!」と、最初から分かっていた顔をする
- 本当は市民だった:ヒーローは謝らず、腕組みで「でも怪しかった!」と言いはる。そのあとオペレーターが「…ワルにしたの、私だけど」と気づく(ワルの札をつけたのはプレイヤーなので)

### ヒーローの動き

ヒーローの動きは、攻撃に限らず全部ハデにする。力の加減ができず、何をしても大げさで、周りまで巻きこむのがStupid Heroらしさ。

攻撃は殴るたびにランダムで選ぶ。次の4つがある。

| 攻撃 | どんな技か | 周りへの巻きぞえ |
|---|---|---|
| 光の突撃 | 全身に光をまとって相手に突っこむ | 通り道の物を壊す |
| 光のパンチ | パンチすると拳の形の光が飛んでいく | 光は相手を突き抜けて、その先の物に当たるまで飛ぶ |
| 踏みつぶし | 高く跳んで、上から踏みつぶす | 着地の衝撃波が左右に広がり、近くの物を壊す |
| 必殺技(まれに出る) | 画面の端まで届く太い光線 | 光線の通り道にある物を全部壊す |

- 選ばれる割合は、光の突撃30%、光のパンチ35%、踏みつぶし30%、必殺技5%
- 光のパンチ、衝撃波、光線は、先にいる市民に当たることがある(巻きぞえ)。当たった市民は「市民のけが」に数える

攻撃以外の動きもハデにする。

| 動き | ハデにするところ |
|---|---|
| 待機 | 体のまわりに光がゆらめく |
| 走る | 光の尾を引く |
| 素通り | 手を振ると、キラキラが飛び散る |
| 待てで止まる | 急ブレーキで地面から火花が散り、足あとが焦げる |
| やっちまったー | 背景に「ガーン」の稲妻が走る |
| まあいいか | 後ろから光が差して「キラーン」 |
| 言いはる | 腕組みでドヤ顔 |
| 勝利ポーズ | 背中で爆発が起きる(特撮ヒーローのように) |

光の見せ方は、メガドライブと同じく半透明は使わない。1コマおきに点滅させて、透けているように見せる。

ワルにした市民を殴ったときは、上の「本性ちらりとヒーローの決めつけ」の通り、ヒーローが言いはる。

巻きぞえで市民を傷つけたとき(ヒーローの雑さのせい):

1. 殴ったあと「やっちまったー!」と頭を抱える
2. 一瞬で立ち直って「まあいいか!」
3. 何事もなかったように次へ進む

オペレーターが「まあいいか、じゃない!」とツッコむ。テンポを落とさないように、1回のプレイの中で2回目からは短い版にする。

### 街が壊れる

路地裏にはゴミ箱、自販機、看板、窓、止めてある車などがある。ヒーローの攻撃やワルの悪さで壊れると、被害額が増える。額は大げさでいい。ほかのステージの物は`docs/STAGE2.md`と`docs/STAGE3.md`にある。

| 物 | 被害額 |
|---|---|
| ゴミ箱 | ¥3万 |
| 窓 | ¥8万 |
| 看板 | ¥15万 |
| 自販機 | ¥80万 |
| 止めてある車 | ¥300万 |

ワルの悪さ(ひったくりなど)も1回¥20万として被害額に足す。突き飛ばしとひったくりは、襲われた市民を「市民のけが」にも数える(財布を抜く、ナイフで脅すだけのものは数えない)。

## ボス

- 波3の仕分けの中に、市民に化けたボスが1人いる。化けた姿は毎回変わる(会社員、おばあさん、買い物袋の女性の3つから選ぶ)
- 化けた姿は市民とほぼ同じだが、どこか1か所だけおかしい(少し大きい、腕に入れ墨がのぞく、など)
- 結果発表でヒーローがボスの前に来たとき:
  - ワルに仕分けていた場合:ヒーローが殴りかかり、ボスが正体を現してボス戦へ
  - 市民に仕分けていた場合:ヒーローが素通りしたあと、ボスが正体を現して周りを壊しながら暴れる(被害額に¥1,000万を足す。地下駐車場は¥1,500万、ショッピングモールは¥2,000万)。そのあとボス戦へ
- 路地裏のボスは、路地裏を仕切っている大柄なワルのボス

### ボス戦

- **行けボタンの連打**。連打の速さでヒーローのラッシュが速くなる
- ボスの体力は連打40回分
- 1秒に10回を超えた分は数えない
- 手が止まっている間はボスが暴れて、1秒ごとに被害額が¥50万増える
- 負けはない。ボスの体力は時間でも少しずつ減り、どんなに遅くても15秒で倒せる
- ボス戦にかかった秒数を記録する
- 連打のたびに画面は揺らさず、殴られた相手だけを揺らす。画面全体の揺れは、ほかの場面の半分の強さにする(揺れる場面が多いので)。ボスを倒したあと(爆発、車や母艦が壊れる、ボスが出てくる)は揺れが続くので、そのさらに半分にする
- ボスを倒したら、波3の答え合わせへ行く
- 地下駐車場とショッピングモールのボスは、体力が半分を切ると車や母艦に乗りこむ(`docs/STAGE2.md`、`docs/STAGE3.md`の「ボス戦」)

- ボスを倒した回数が1回以上になると、次のステージが開く(上の「ステージを選ぶ画面」)

- iPhoneのSafariは、しばらく開かなかったサイトの記録を消すことがある。消えることはあると割り切り、「ホーム画面に追加すると記録が消えにくい」と一文出す(タイトル画面と、共有の画像を大きく出した画面)

## 一時停止と設定

中断のボタンを押すと、ゲームを止めて小さなメニューを重ねて出す。見出しは「一時停止」。

| 項目 | すること |
|---|---|
| 光と揺れを弱くする | 画面全体を白く光らせない。画面の揺れは大きい揺れだけを1ドットにし、小さい揺れは出さない。殴られた相手などの絵だけの揺れは半分にする |
| ゆっくりモード | 仕分けの時間を1.5倍にする(ショッピングモールでは、タイムセールラッシュで人が来る間隔も1.5倍。フリープレイでは、人と人の間やマークの長さなどを1.5倍。`docs/FREEPLAY.md`)。取れる称号は変わらない |
| 音 | 音のオンとオフ |
| つづける | メニューを閉じて再開する |
| タイトルへ | そのプレイを記録せずに終わって、タイトルへ |

- 切りかえは行のどこを押してもよい(指が届きやすいように)。止めた指で押してしまわないように、出てから0.3秒は押しても効かない
- 設定はそのスマホの中に覚える(キーは`stupidhero.settings.v1`)。「光と揺れを弱くする」は、端末の「視差効果を減らす」がオンなら最初からオン
- 一時停止ができるのは、掛け合い、仕分け、結果発表(タイムセールラッシュとフリープレイを含む)、ボス戦
- 止めている間は、そのシーンの時計、動き、アニメ、曲を止める

## スマホのブラウザで気をつけること

- **スワイプ**:人物の絵の上から始めたときだけ受け付ける。画面の左右の端から始まった動きは無視する(Safariの「戻る」とぶつかるため)
- **連打**:指が触れた瞬間に数える。2本の指で交互に押しても数える。2回タップでの拡大、長押しのメニュー、文字の選択、下に引っぱって再読み込み、を止める
- **音**:iPhoneはタップするまで音が出ず、マナーモードだと鳴らないことが多い。音がなくても遊べるようにし、合図を音だけに頼らない。音のオン/オフボタンを付ける。共有メニューやアプリの切り替えから戻ったら、次のタップで音を再開する
- **画面を離れたとき**:通知やアプリの切り替えで画面が隠れたら、時計とゲームを止める。戻ったら一時停止のメニューが出ていて、「つづける」で再開する
- **字の位置**:iPhoneのSafariでは、字の上の端をそろえて描くと、Chromeより字が下にずれて切れる。字の下の線をそろえて描き、どのブラウザでも同じ所に出す

## 作り方(技術)

- TypeScriptとPhaser 3で作る。ビルドはVite
- 音はWeb Audioで合成する。メガドライブ風のFM音源とPSGの音色にする。音の出口は1つにまとめる(Phaserの音の仕組みは使わない。取り合いにならないように)
- 公開はGitHub Pages(サーバーなしで動く)。公開のしかたは`docs/DEVELOP.md`
- 絵は1コマごとの画像を並べた画像ファイル(スプライトシート)の形で扱う。いまはコードで描いた絵を、起動したときにこの形で作っている。PNGを置けばそのキーだけ差し替わる(`docs/DEVELOP.md`の「絵を差し替える」)
- 起動したときは「よみこみちゅう…」と出して、絵と字を用意する
- 共有は、実際のiPhoneとAndroidで、X、LINE、Instagramへ送れるかを確かめる(共有のしかたを変えたときも)

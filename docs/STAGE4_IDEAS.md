# ステージ4 超能力のヴィラン 3つの案

ステージ4は最後のステージです。仕様を決める前に、3つの案を並べて比べるためのメモです。どれにするか決まったら、決まった案をもとに`docs/STAGE4.md`を書き、このファイルは消します。

## 3つの案に共通すること

- 悪党は超能力のヴィラン。見た目は普通の人で、能力のもれ(静電気、浮く小物)が手がかりになる(`docs/SPEC.md`の「これから作るかもしれないもの」)
- 波は4つにする。最後の波にボスが紛れる
- 出てくる人を増やす。1つの波の人数を増やし、見た目も6〜8種類にする(ステージ1〜3は4種類ずつ)
- 見分け方は、これまでの流れの続きにする

| ステージ | 見分け方 |
|---|---|
| 1 路地裏 | 1人をよく見る |
| 2 地下駐車場 | 前の人と比べる |
| 3 ショッピングモール | 少し待って動きを見る |
| 4 | 案ごとに違う(下に書く) |

### 波と人数(たたき台)

| 波 | 人数 | 制限時間 | メモ |
|---|---|---|---|
| 1 | 5人 | 30秒 | 練習の波。もれが分かりやすい人を1人入れる |
| 2 | 6人 | 28秒 | |
| 3 | 7人 | 30秒 | 途中のイベントはこの波のあと |
| 4 | 7人とボス | 32秒 | |

- 1つの波のヴィランは2〜3人(波4は3人とボス)
- 数字は遊んで直す。ステージ3と同じく、全員をじっくり見ると時間が足りない長さにする

## 案A 雨の夜の駅前

### 舞台

雨がふる夜の駅前の大通り。ぬれた地面にネオンが映る。大きな街頭ビジョン、横断歩道、駅の入口、止まっているタクシー、屋台のラーメン。

- 雨の粒は、煙や光の粒と同じようにコードで点を打って描く。手前ほど粒を大きく速くする
- ぬれた地面は、ネオンの色を市松模様(ディザ)で映す
- ときどき遠くで雷が光り、一瞬だけ背景が明るくなる(「光と揺れを弱くする」では出さない)

### 見分け方:周りを見る

もれは本人ではなく、本人の周りに出る。

- ヴィランの頭の上だけ、雨がよけて落ちる
- 足元の水たまりが波立たない、または逆に浮き上がる
- 近くのネオンや街灯がちらつく(静電気)

紛らわしい市民:

- 大きな傘をさしていて、雨がよけているのか分からない人
- 屋根の下で雨宿りしていて、もともと雨が当たらない人
- セーターで静電気がすごい人(髪が逆立つ)

### 出てくる人(8種類)

| 見た目 | 市民にもある紛らわしさ |
|---|---|
| 傘の会社員 | 傘で頭の上が見えない |
| レインコートの配達員 | フードで髪が見えない |
| 雨宿りの学生 | 屋根の下にいる |
| 手品の大道芸人 | 本当に小物を浮かせる(手品の糸が見える) |
| 占いのおばあさん | 水晶玉が光る |
| セーターの観光客 | 静電気で髪が逆立つ |
| 犬の散歩の人 | 犬がほえる(ヴィランにもほえる) |
| 客引き | ネオンの前に立つので光がちらつく |

### 結果発表で足す遊び

見逃したヴィランは、念力で看板や自転車、自販機を持ち上げて、通りがかりの人に投げようとする。浮いている間に行けを押すと、ヒーローが走って殴り、物はその場に落ちて壊れる(被害額が増える)。押さないと投げられて市民のけがになる。

### 途中のイベント:停電

波3のあと、雷が落ちて街が真っ暗になる。暗い中を人が次々に走ってくる。見えるのは静電気の青白い火花だけ。ヒーローは暗くて何もしないので、火花が出た人にだけ行けを押す。

- ショッピングモールのタイムセール(市民にだけ待て)の逆で、ワルにだけ行けを押す
- 画面は暗いが、真っ黒にはしない(人の輪郭は見えるくらい)

### ボス

念力のヴィランの親玉。正体を現すと雨が空中で止まる。ボス戦の途中で、街頭ビジョンを持ち上げて落とそうとする。

### よいところと気になるところ

- よい:雨とネオンで、4つのステージの中でいちばん見た目が派手になる。「周りを見る」は、これまでの3つとはっきり違う
- よい:停電は、画面が暗くなるだけで場面が大きく変わるので驚きがある
- 気になる:雨の粒をずっと動かすので、古いスマホで重くならないか確かめが要る
- 気になる:暗い画面は、明るい屋外では見にくい

## 案B 生放送中のテレビ局

### 舞台

ヒーローの活躍を生放送する特番の収録スタジオ。セット、本番中の赤いランプ、大きなカメラ、照明のやぐら、観覧席、後ろにモニターがずらりと並ぶ壁。波ごとに、楽屋の廊下、スタジオ、観覧席、屋上のヘリポートと場所が変わる。

- 画面の上の端に「LIVE」の札と、にせのテロップが流れる(文字はコードで入れる)
- 照明がゆっくり動き、人を照らすスポットライトの丸が動く

### 見分け方:うその手がかりを見抜く

最後のステージなので、これまで信じていた手がかりが信じられなくなる。

- ヴィランが近くに来ると、後ろのモニターの映像が乱れる(静電気)
- 心を読むヴィランは、プロフィールやオペレーターの一言を書きかえる。書きかえられた文は、ときどき文字がぶれる
- 波4では、オペレーターの一言がまるごと操られることがある(声の色が変わる)

### 出てくる人(8種類)

| 見た目 | 市民にもある紛らわしさ |
|---|---|
| AD(アシスタント) | 機材を持っていて、周りのモニターが乱れる |
| アイドル | 紙吹雪が舞っている |
| お笑い芸人 | 変なポーズで浮いて見える |
| 天気予報のお姉さん | 風船の地球儀を持っている |
| マジシャン | 本当に物を浮かせる |
| ヒーローのそっくりさん | ヒーローと同じ服 |
| 観覧のおばちゃん | うちわが勝手に揺れる(扇風機のそば) |
| 子役 | 大人びたことを言う(心を読んでいそうに見える) |

### 結果発表で足す遊び

見逃したヴィランは、照明やカメラを念力で浮かせて、観覧席に落とそうとする。落ちる前に行けで止める。カメラが壊れると、画面が一瞬砂あらしになる。

### 途中のイベント:握手会

波3のあと、生放送の握手会が始まる。ファンが列になって次々にヒーローの前に来る。ヒーローは全員と握手しようとする。ヴィランと握手するとヒーローが一瞬操られるので、ヴィランにだけ行けを押して先に殴る。

### ボス

番組のプロデューサー(実は心を読むヴィランの親玉)。ボス戦の途中で、ヒーローを操って行けのボタンを一瞬だけ効かなくする(ボタンがぶれる)。

### よいところと気になるところ

- よい:ヒーローがテレビに出る晴れ舞台で、最後のステージらしいお祭り感が出る
- よい:「手がかりを疑う」遊びは、これまでのどのステージにもない
- 気になる:文を書きかえる仕組みは作るのも説明するのも手間。うそが多いと、ただイライラするゲームになる
- 気になる:スタジオは明るく平らな場所なので、背景の見せ場を作るのに工夫が要る

## 案C 浮かんだ街

### 舞台

超能力の親玉が街ごと空に持ち上げた。浮かんだ道のかけらの上を進む。波ごとに、これまでのステージのかけらが舞台になる。

| 波 | 舞台 |
|---|---|
| 1 | 浮かんだ路地裏 |
| 2 | 浮かんだ地下駐車場(天井がはがれて空が見える) |
| 3 | 浮かんだショッピングモール |
| 4 | 夜明けの空の上。親玉のいる、がれきでできた塔 |

- 遠くで車やマネキンやガチャガチャが、ゆっくり回りながら浮いている
- 足元の道の下は雲。ときどき小さながれきが下へ落ちていく

### 見分け方:浮く小物と、これまでの見分け方の総まとめ

- ヴィランの近くでは、小物(小銭、スマホ、ボタン)が少し浮く。髪の毛の先が逆立つ
- 親玉に操られた、これまでの悪党(チンピラ、ギャング、宇宙人)も出てくる。波1は路地裏の見方、波2はおそろいの色、波3はくずれ、波4は全部がまざる

### 出てくる人

新しい見た目は4種類(ヴィランと市民の組)にして、これまでの人も出す。

| 新しい見た目 | 市民にもある紛らわしさ |
|---|---|
| パジャマで逃げてきた人 | 寝ぐせで髪が逆立つ |
| 消防士 | ホースの水しぶきが浮いて見える |
| ペットを抱えた人 | 猫の毛が静電気で逆立つ |
| 空の中継をする記者 | マイクのコードが揺れる |

### 結果発表で足す遊び

見逃したヴィランは、足元の道を割って、市民を浮かせて空へ飛ばそうとする。行けで止める。見逃した昔の悪党は、それぞれのステージの悪さをする(ギャングは仲間を呼ぶ、宇宙人はUFOを呼ぶ)。

### 途中のイベント:ボスの復活

波3のあと、操られたこれまでの3人のボスが順に出てくる。1人ずつ短い連打で倒していく。

### ボス

超能力の親玉。ボス戦の途中で、浮かんだ道をかたむけてヒーローをすべらせる(画面が少しかたむく)。

### よいところと気になるところ

- よい:最後のステージらしく、これまでの全部が出てくる。出てくる人がいちばん多くなる
- よい:これまでの絵を使えるので、新しく描く絵が少なくてすむ
- 気になる:ステージ4だけの新しい見分け方が弱い(浮く小物以外は、これまでのまとめ)
- 気になる:ギャングやUFOの仕組みを1つのステージでまぜて動かすので、組み合わせの確かめが増える

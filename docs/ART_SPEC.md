# Stupid Hero 絵の要件定義(ChatGPTで作る用)

いまの絵は全部コードで描いています(`src/art/`。`world/`がステージ1、`world2/`がステージ2、`world3/`がステージ3、`hero/`がヒーローと顔とエフェクト)。この要件に合わせてChatGPTなどでPNGを作れば、置くだけでそのキーの絵が差し替わります。置き方は`docs/DEVELOP.md`の「絵を差し替える」にあります。置いたら開発用のページ`/dev/art.html`で、差し替わったか(キーの横に「PNG」と出る)、大きさとコマの区切りが合っているかを見られます。

シートの行の並び、コマ数、速さ、大きさの元は`src/art/sheets.ts`の表です。このファイルの表はそれと同じにしてあります。食いちがったときは`sheets.ts`が正しいので、こちらを直します。

ステージ2と3の人の見た目の決まり(何が手がかりになるか)は`docs/STAGE2.md`と`docs/STAGE3.md`の「見た目」「手がかり」にあります。ここには、絵を描くのに要ることだけを書きます。

## 全体の決まり

| 項目 | 決まり |
|---|---|
| ゲーム画面の大きさ | 横216ドット、縦384〜468ドット(縦持ち。縦はスマホの縦横の比で決まる) |
| アクション部分 | 上の横216×縦214ドット |
| 目指す見た目 | メガドライブのベルトアクション(ベア・ナックル、ゴールデンアックスあたり) |
| 色の数 | キャラ、物、エフェクトは1枚につき、透明を除いて15色まで |
| 使える色 | R、G、Bそれぞれ 0 / 36 / 73 / 109 / 146 / 182 / 219 / 255 の8段階から選ぶ |
| 共通の色 | 市民と悪党は、肌、髪、ふちの色を同じにする。服の色だけ変える(ステージ2と3の人も同じ色を使う) |
| 背景の色の数 | 1つのステージの背景3枚を合わせて45色まで |
| ふち取り | 1ドットの濃い色のふち。真っ黒ではなく、少し色みのある黒(R36 G0 B36) |
| 光の向き | 左上から当たる(左右反転したときに右上からになるのはあきらめる) |
| 禁止 | ぼかし、半透明、アンチエイリアス、グラデーション、ドットの大きさがばらばらな絵 |
| 許すもの | 背景だけは、2色を市松模様に並べて中間の色に見せる描き方(ディザ)を使ってよい |
| 文字 | キャラ、物、背景に文字を描かない。看板の文字などはコードで入れる |
| ファイル形式 | 背景が透明なPNG |
| キャラの向き | すべて右向きで描く(左向きはゲームの中で反転する) |

### 決まった所にしか使わない色

| 色 | 決まり |
|---|---|
| 明るい緑(R0 G255 B0) | どの絵にも使わない。ChatGPTに頼むときの背景色にするため |
| 赤紫(R255 G0 B255) | ステージ2の人の小物(腕章、首の布、ヘアバンド、スカーフ)だけに使う。ゲームの中で、この色のドットだけを人ごとの色に塗り替える(`src/art/recolor.ts`)。ほかの所に使うと、そこも塗り替わってしまう |
| 黄緑の3色(R219 G255 B146、R146 G255 B0、R73 G182 B0) | ステージ3の宇宙人のくずれ、合図の光、親玉の目と触角、UFOと母艦の光だけに使う(`src/art/world3/palette.ts`の`GLITCH`)。市民の絵には使わない(使うと宇宙人に見える) |

コードで描いた絵がここまでの色の決まりを守っているかは、`src/art/artRules.test.ts`で確かめています(`npm test`)。PNGで差し替えた絵は確かめないので、作るときに気をつけます。

## キャラの絵の大きさ

| 種類 | 1コマの大きさ | 身長の目安 |
|---|---|---|
| ヒーロー、市民、悪党 | 64×64ドット | 足元から頭まで52〜56ドット。4.5〜5頭身、頭の高さは11〜12ドット |
| ボスの化けた姿 | 64×64ドット | 58〜60ドット(わざと少し大きくする。着ぐるみだけは市民とほぼ同じ) |
| ボス(正体) | 96×96ドット | 84〜90ドット |
| 顔のカットイン | 32×32ドット | 胸から上 |

位置のそろえ方:

- 立っているコマは、足の裏をコマの下から4ドット上にそろえる(96×96のボスなら y=91)
- 体の真ん中は、コマの左から32ドット目(ボスは48ドット目)にそろえる
- 空中のコマは、体の真ん中をそろえる。跳ぶ高さや吹っ飛ぶ動きはゲームの中で動かす
- 寝ているコマは、体の下側を足の裏の線にそろえる
- 攻撃で腕や足を伸ばすときも、コマからはみ出さない。はみ出す光やがれきは別の絵にする

## 仕分けの画面での見え方

仕分けの画面では、キャラの絵をちょうど2倍に拡大して見せます(1.5倍などにはしない)。それでも1ドットはスマホの上で0.6mmほどなので、手がかりは次のように描きます。

- 手がかり(ナイフの柄、財布、女物のバッグなど)は3×3ドット以上
- 手がかりには、そのキャラでほかに使っていない目立つ色を1色あてる
- ポケットのふくらみのような形の違いは、輪郭だけでなく明るい色の点を置いて見せる
- 仮の絵ができたら、実際のスマホで2倍の表示を見て確かめる

### 「持ち物」の窓

人の右の「持ち物」の窓は、コマの中の決まった四角(16×14ドット)を3倍にして映します。四角の場所は見た目ごとに`src/art/clueSpots.ts`で決めてあります。

- 窓は、人の絵と同じコマを映す。仕分けの画面での動き(行2)の4コマのどれでも、手がかりがその四角に入るように描く(入らなければ四角の場所を直す)
- 同じ見た目の市民、ワル、ボスの化けた姿は、同じ四角を使う(映る場所で正体が分からないように)。手がかりも同じあたりに置く
- ステージ3の宇宙人は、くずれ(行7)も窓に映る。くずれの1コマ目が四角の中で目に見えて変わるように描く

| 見た目 | 四角に入れるもの |
|---|---|
| パーカーの男 | ポケットのあたり(市民は茶色の財布、ワルは黄色いナイフの柄) |
| スーツの男 | 胸と腕のあたり(市民は金の腕時計、ワルは赤いバッグ。ボスは腕の水色の入れ墨) |
| 買い物袋の女性 | 袋の口と手 |
| おばあさん | 背中の手(ボスは腕の水色の入れ墨) |
| モヒカン | ナイフを持つ手 |
| ステージ2の4人 | 小物(腕章、首の布、ヘアバンド、スカーフ)。女ボスの金の小物も入る |
| ステージ3の4人 | くずれる場所(着ぐるみは頭、店員は目、学生は腕のつけね、おじさんは胴)。親玉の化けた姿は、着ぐるみの触角だけが入る |

## ファイルの並べ方(スプライトシート)

- 1つのファイルに、1体分の動きを全部並べる
- 1行が1つの動き。左から順にコマを並べる
- 1行のコマ数が足りないところは透明のままにする
- 行の順番は下の表の通りにする(順番が変わるとゲームで違う動きが出る)
- 表の「速さ」は1秒に何コマ進むか、「当たり」はそのコマで攻撃が当たる(物が壊れる、相手が吹っ飛ぶ)という意味

## ChatGPTで作る手順

ChatGPTの画像はドットの大きさがそろわず、コマごとに形や色が少しずつずれます。そのまま使えないので、次の手順で作ります。

1. **設定画を作る**:キャラごとに、右向きの大きな立ち絵と、身長56ドットくらいの小さな立ち絵を並べた1枚を作る。気に入ったら、以後はこの画像を毎回添えて「このキャラで」と頼む
2. **色を決める**:設定画から、そのキャラの15色を8段階の値で決めて、色の一覧としてここに書き足す。以後のコマは全部この15色に置き換える
3. **1回に頼む量を少なくする**:1枚に1つの動きまで。並べ方は、横長(1536×1024)の画像なら横3コマ×縦2段、正方形(1024×1024)なら横2コマ×縦2段
4. **背景は明るい緑一色にしてもらう**(#00FF00)。キャラに緑を使わないので、あとで背景だけきれいに消せる
5. **変換スクリプトで整える**:次の順で処理する。このスクリプトはまだない。ChatGPTの絵ができたら作る
   1. 画像のふちから緑をたどって消し、背景を透明にする(キャラの中の似た色は消えない)
   2. 背景でない部分のかたまりを1コマとして探して切り出す
   3. キャラの身長が56ドットになるように縮める(ドットの大きさは絵から読み取る)
   4. 決めておいた15色に置き換える
   5. 足の裏と体の真ん中をそろえて、決まった並びのシートにする
6. **最後に手で直す**:無料のドット絵ソフト(Piskel、LibreSpriteなど)で1コマずつ見て、ずれや色のにじみを直す。ここは必ず要る

### 頼み方の例

設定画:

```
メガドライブ時代のベルトアクションゲーム風のドット絵で、キャラの設定画を描いてください。
・キャラ:女の子のヒーロー。いつも元気で自信満々。赤と青と金のスーツにマント、目元にマスク、明るい金髪。胸のマークは星
・右向きの大きな立ち絵と、身長56ドットくらいの小さな立ち絵を横に並べる
・4.5〜5頭身
・荒いドット絵。ドットをくっきり描く。色は15色以内
・ぼかし、グラデーション、光のにじみ、影、地面、文字、番号、枠線は描かない
・ふちは1ドットの濃い紫がかった黒
・背景は#00FF00の一色
```

動き:

```
添付の設定画と同じキャラで、ゲーム用のドット絵を描いてください。
・動き:「やっちまったー!」と両手で頭を抱えてのけぞる。6コマ
・並べ方:横3コマ×縦2段。左上から右へ、1段目のあとに2段目
・どのコマもキャラの大きさを同じにし、足の裏の高さと体の左右の位置をそろえる
・右向き。見る角度は設定画の右向きと同じ
・荒いドット絵。身長は56ドットくらい。ドットをくっきり描く
・色は設定画の色だけ。ぼかし、グラデーション、光のにじみ、影、地面、文字、番号、枠線は描かない
・背景は#00FF00の一色
```

ステージ2の人を頼むときは「小物は#FF00FFの一色で塗る」、ステージ3の宇宙人のくずれを頼むときは「光る所は黄緑(#92FF00)」を足します。

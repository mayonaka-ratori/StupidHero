# Stupid Hero 絵の要件定義(ChatGPTで作る用)

最初の版の絵はコードで作ります。あとでこの要件に合わせてChatGPTで絵を作れば、ファイルを置き換えるだけで差し替わるようにしておきます。

## 全体の決まり

| 項目 | 決まり |
|---|---|
| ゲーム画面の大きさ | 横216×縦384ドット(縦持ち) |
| アクション部分 | 上の横216×縦214ドット |
| 目指す見た目 | メガドライブのベルトアクション(ベア・ナックル、ゴールデンアックスあたり) |
| 色の数 | キャラ1体につき、透明を除いて15色まで |
| 使える色 | R、G、Bそれぞれ 0 / 36 / 73 / 109 / 146 / 182 / 219 / 255 の8段階から選ぶ |
| 背景の色の数 | 路地裏の背景全部で45色まで |
| ふち取り | 1ドットの濃い色のふち。真っ黒ではなく、少し色みのある黒(例:R36 G0 B36) |
| 光の向き | 左上から当たる |
| 禁止 | ぼかし、半透明、アンチエイリアス、グラデーション、ドットの大きさがばらばらな絵 |
| ファイル形式 | 背景が透明なPNG |
| キャラの向き | すべて右向きで描く(左向きはゲームの中で反転する) |

## キャラの絵の大きさ

| 種類 | 1コマの大きさ | 身長の目安 |
|---|---|---|
| ヒーロー、市民、悪党 | 64×64ドット | 足元から頭まで52〜56ドット |
| ボス(正体) | 96×96ドット | 84〜90ドット |
| オペレーターの顔(カットイン) | 48×48ドット | 胸から上 |

- 足元は、どのコマもコマの下から4ドット上にそろえる
- 体の真ん中は、コマの左から32ドット目(ボスは48ドット目)にそろえる
- 攻撃で腕や足を伸ばすときも、コマからはみ出さない

仕分けの画面ではこの絵を2倍に拡大して見せます。ナイフの柄やポケットのふくらみなど、見分ける手がかりは64×64の大きさでも見える太さで描きます。

## ファイルの並べ方(スプライトシート)

- 1つのファイルに、1体分の動きを全部並べる
- 1行が1つの動き。左から順にコマを並べる
- 1行のコマ数が足りないところは透明のままにする
- 行の順番は下の表の通りにする(順番が変わるとゲームで違う動きが出る)

## ChatGPTで作るときのコツ

ChatGPTの画像はドットの大きさがそろわず、色も増えがちです。そのまま使えないので、次の手順で作ります。

1. **先に設定画を作る**:キャラごとに、正面と横向きの立ち絵を1枚作る。気に入ったら、以後はこの画像を毎回添えて「このキャラで」と頼む
2. **1回に頼む量を少なくする**:1枚に1つの動き(4〜6コマ)まで
3. **背景色を決めておく**:背景は透明ではなく、真っ赤紫一色(#FF00FF)にしてもらう。あとで透明に変える
4. **大きめに描いてもらう**:「1ドットを8×8の四角で描いて」と頼み、ドットの格子が見える状態で出してもらう
5. **仕上げは変換スクリプトで**:できた絵を、ドットの大きさをそろえる、色を15色に減らす、背景を透明にする、コマを切り出して並べる、の順で整える。このスクリプトは絵ができた段階で私が用意します

### 頼み方の例

設定画:

```
メガドライブ時代のベルトアクションゲーム風のドット絵で、キャラの設定画を描いてください。
・キャラ:女の子のヒーロー。いつも元気で自信満々。赤と青と金のスーツにマント、目元にマスク、明るい金髪
・正面向きと右向きの立ち絵を横に並べる
・1ドットを8×8の四角で描き、ドットの格子がはっきり分かるように
・色は15色以内。ぼかしやグラデーションは使わない
・ふちは1ドットの濃い紫がかった黒
・背景は#FF00FFの一色
```

動き:

```
添付した設定画のキャラで、「やっちまったー!」と両手で頭を抱えてのけぞる動きを6コマ描いてください。
・右向き
・6コマを左から右へ1列に並べる。コマの間は同じ間隔をあける
・どのコマも足元の高さをそろえる
・1ドットを8×8の四角で描く。色は設定画と同じ色だけを使う
・背景は#FF00FFの一色
```

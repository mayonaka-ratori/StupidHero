## 手がかり

ステージ1の4つ(見た目、動き、プロフィール、オペレーターの一言)に、次を足す。

### 動きのくずれ

- 宇宙人は、出てきてしばらくは人間らしく動く。そのあと2〜3秒に1回、一瞬(0.2秒くらい)だけ人間にはできない動きになる
- 市民のぎこちない動きも同じくらいの間をあけて出す(間の長さで分からないように)
- プロフィールと一言の文字送りの間(時計が止まっている間)は、くずれを出さない。待って確かめるには時間を使う、という形にする
- 「持ち物」の窓は、動くところ(着ぐるみの首、目、腕、体)を大きく映す。同じ見た目の人は、市民でも宇宙人でも同じ場所を映す
- 波1の練習用の宇宙人は、くずれを少し早め、少し長めにする

1つの手がかりだけでは決められず、2つ3つ合わせると分かる、くらいの難しさを目指す。

## 結果発表

ステージ1と同じ決まり(早送り、本性ちらり、ヒーローの決めつけも同じ)に、次を足す。

- 本性ちらりは、宇宙人なら目が一瞬緑に光って「ピピッ…」。市民は今までと同じ「ぺこり」

### UFOで連れ去る

- 見逃した宇宙人(市民に仕分けた宇宙人)は、ヒーローが素通りしたあと、悪さの代わりに空へ合図を送る
- UFOが下りてきて、まだヒーローが通っていない先の市民のうち、いちばん近い人を光で吸い上げ始める
- 先に市民がいないときは、UFOは宇宙人だけを乗せて去る(「逃がした」に数える)
- UFOの上に行けのマークを出す。行けの使い方は、初めてUFOが来たときに「UFOが来た!行けで落として!」と教える

### 行けで殴り落とす

- 3秒以内に行けを押すと、ヒーローが跳んでUFOを殴り落とす。吸い上げられていた市民は無事に下りる
- 宇宙人も一緒に倒れる(撃破に数える)
- UFOは落ちた所の物を壊す。被害額にUFOの分(¥800万)と壊れた物の分を足す
- 落ちたUFOは市民を巻きこまない(画面がごちゃごちゃしないように)

### 連れ去られる

- 行けを押さないまま3秒たつと、市民は連れ去られ、UFOは宇宙人を乗せて去る
- 連れ去られた市民は「市民のけが」に数え、内わけに「さらわれた」を足す
- 宇宙人は「逃がした」に数える

### 店が壊れる

| 物 | 被害額 |
|---|---|
| ガチャガチャ | ¥5万 |
| マネキン | ¥10万 |
| ショーウィンドウ | ¥30万 |
| 噴水 | ¥150万 |
| エスカレーター | ¥800万 |

### 数え方の追加

| 数字 | 追加 |
|---|---|
| 悪党を倒した | UFOごと倒した宇宙人も入る |
| 市民のけが | 連れ去られた市民が入る(内わけは「さらわれた」) |
| 逃がした | UFOで去った宇宙人が入る |
| 被害額 | 落ちたUFOの¥800万 |

結果画面の数字の窓には、「UFOを落とした」数を小さく1行足す。

## ボス:宇宙人の親玉

- 波3の仕分けの中に、市民に化けた親玉が1人いる。化けた姿は、寝不足の店員、買い物客のおじさん、着ぐるみのバイトの3つから選ぶ
- 化けた姿は市民とほぼ同じだが、どこか1か所だけおかしい(名札が逆さ、耳がとがっている、着ぐるみから触角がのぞく)
- 親玉の動きは、くずれない(ボスはふりが上手)。見た目のおかしい所で見分ける
- 正体を現すところはステージ1と同じ流れ

### ボス戦

- 連打で戦うのはステージ1と同じ。体力は連打40回分、最長15秒、負けはない
- 体力が半分を切ると、親玉が天井を破って母艦を呼び、乗りこむ
  - 連打すると、ヒーローが母艦ごと殴る(連打はそのまま体力を減らす)
  - 手が止まっている間は、母艦が光線で床を焼く。1秒ごとに被害額¥150万
  - 倒したときは、母艦が噴水に落ちて爆発し、親玉が目を回して出てくる
- 連打で揺れるのは、殴られている親玉(乗りこんだあとは母艦)だけ。画面の揺れはステージ1と同じくひかえめにする
- 親玉を市民に仕分けていた場合は、正体を現したあと母艦の光線でモールを焼く(被害額に¥2,000万を足す)

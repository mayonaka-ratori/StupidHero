### 時間の見積もり

くずれを待つと、1人に約5.5秒かかる(初めてくずれるまで平均4.5秒と、スワイプまでの1秒)。待たずに決めると1人3秒くらい。

| 波 | 1人あたりの時間 | 全員待つと | 待てる人数の目安 |
|---|---|---|---|
| 1 | 6.0秒 | 27.5秒(間に合う) | 全員。練習なので待つことを覚える |
| 2 | 4.7秒 | 33秒(足りない) | 6人中3〜4人 |
| 3 | 4.3秒 | 38.5秒(足りない) | 7人中2〜3人。親玉はくずれないので、待っても何も起きない |

- 波3で親玉を待ち続けると、何も起きないまま時間が減る。「くずれない人は市民」と思いこむと親玉を見逃す
- ゆっくりモード(1.5倍)では、どの波も全員を待てる。ゆっくりモードは遊びやすくするためのものなので、それでよい
- 数字は遊びながら直す

## 見た目

ステージ3の人は新しく4種類。どれも市民と宇宙人の組にする。宇宙人も、同じ見た目の市民と同じぎこちない動きをする(ぎこちなさだけでは分からないように)。違うのは、ときどき出るくずれだけ。

| 見た目 | 市民も宇宙人もするぎこちなさ | 宇宙人だけのくずれ |
|---|---|---|
| 着ぐるみのバイト | 前が見えずにふらつく | 着ぐるみの首が一回転する |
| 寝不足の店員 | かくっと船をこぐ | まばたきが横に閉じる |
| ロボットダンスの学生 | カクカク踊る | 腕がのびて戻る |
| 買い物客のおじさん | 腰をさする | 一瞬、体の色がちらつく |

## 手がかり

ステージ1の4つ(見た目、動き、プロフィール、オペレーターの一言)に、次を足す。

### 動きのくずれ

- 宇宙人のくずれは、仕分けの時計で3〜6秒たったときに初めて出る。何秒にするかは人ごとに0.5秒きざみで決める。そのあとは3秒に1回、0.2秒出る
- 数えるのは仕分けの時計だけ。プロフィールと一言の文字送りの間や、一時停止の間は時計が止まるので、くずれまでの時間も進まない。待って確かめるには時間を使う、という形にする
- 市民のぎこちない動きは、ずっとくり返す(仕分けの動きの行)
- くずれは、ぎこちない動きとは別の行に描き、いつ出すかはコードが決める(動きの行に入れると、くり返すたびに毎回くずれるため)
- 波1の練習用の宇宙人は、1.5秒で初めてくずれ、そのあとは2秒に1回、0.3秒出る
- 見た目、プロフィール、一言は今まで通り「どちらとも取れる」ものにするが、くずれを待たなくても決められる人が波に何人かいるようにする

### 「持ち物」の窓

- 窓の四角(16×14ドット)に、くずれる場所が入るようにする。着ぐるみは頭、店員は目、学生は腕のつけね、おじさんは胴
- 同じ見た目の人は、市民でも宇宙人でも親玉でも同じ場所を映す
- 「腕がのびる」は四角からはみ出してよい(のび始めが四角に入ればよい)。四角の場所は絵ができてから決める

### 仕分けの画面に足す表示

足さない。ステージ2の「見た小物」のような札は、前の人と比べるための表示だった。ステージ3は目の前の人の動きを見るステージなので、目を人から離させる表示は置かない。くずれを見たかどうかは、プレイヤーが自分で覚えておく。

1つの手がかりだけでは決められず、2つ3つ合わせると分かる、くらいの難しさを目指す。

## 結果発表

ステージ1と同じ決まり(早送り、本性ちらり、ヒーローの決めつけも同じ)に、次を足す。

- 本性ちらりは、宇宙人なら目が一瞬光って「ピピッ…」。市民は今までと同じ「ぺこり」
- 光の色は明るい緑(R0 G255 B0)を使わない(ART_SPECで使わない色)。黄緑(R146 G255 B0)にする

### UFOで連れ去る

- 見逃した宇宙人(市民に仕分けた宇宙人)は、ヒーローが素通りしたあと、悪さの代わりに空へ合図を送る。合図そのものの被害額は0
- 連れ去られるのは、仕分けに出てこない通りがかりの買い物客。UFOが来るときに、ヒーローの少し先に1人歩いてくる(仕分けた人から選ぶと、その人が市民だと分かってしまうため)
- 時間の流れ

| 順 | すること | 長さ |
|---|---|---|
| 1 | 宇宙人が空へ合図を送る | 0.8秒 |
| 2 | UFOが下りてくる | 1秒 |
| 3 | 買い物客を光で吸い上げる。UFOの上に行けのマークが出る | 3秒 |
| 4 | 行けを押さなかったら、買い物客と宇宙人を乗せて去る | 1秒 |

- 行けの使い方は、初めて行けのマークが出たときに「UFOが来た!行けで落として!」と教える
- UFOは1機ずつ来る。前のUFOが終わるまで、次の宇宙人は合図を送らずに待つ

### 行けで殴り落とす

- 吸い上げている間に行けを押すと、ヒーローが跳んでUFOを殴り落とす。買い物客は無事に下りる
- 宇宙人も一緒に倒れる。「悪党を倒した」に入れ、「行けで倒した」にも数える(追い打ちの鬼に数える)
- UFOはその場の真下に落ちる。被害額にUFOの分(¥300万)を足し、真下に物があれば1つ壊す
- 落ちたUFOは市民を巻きこまない(画面がごちゃごちゃしないように)
- SPECでは「待てと行けは押しても何も減らない」としている。ここも回数は減らないが、押すと被害額が増える。行けを押すかどうか迷わせるための例外として、ここだけにする

### 連れ去られる

- 行けを押さないまま3秒たつと、買い物客は連れ去られ、UFOは宇宙人を乗せて去る
- 連れ去られた買い物客は「市民のけが」に数える。けがの理由に「さらわれた」を足す(今の「なぐった」「まきぞえ」「ワルにやられた」に続く4つ目)
- 宇宙人は「逃がした」に数える

### 店が壊れる

ヒーローのふつうの攻撃でも、ステージ1と同じように物が壊れる。

| 物 | 被害額 | 大きさ |
|---|---|---|
| ガチャガチャ | ¥5万 | 24×32 |
| マネキン | ¥10万 | 24×56 |
| ショーケース | ¥30万 | 32×32 |
| 噴水 | ¥150万 | 64×40 |
| エスカレーター | ¥800万 | 96×64 |

### 数え方の追加

| 数字 | 追加 |
|---|---|
| 悪党を倒した | UFOごと倒した宇宙人も入る |
| 市民のけが | 連れ去られた買い物客が入る(内わけは「さらわれた」) |
| 逃がした | UFOで去った宇宙人が入る |
| 被害額 | 落ちたUFOの¥300万 |

結果画面の数字の窓には、「UFOを落とした」数と、タイムセールラッシュのまとめを小さく1行ずつ足す。低い画面で入らなければ、1行にまとめる。

## タイムセールラッシュ

波2の結果発表が終わったあと、答え合わせの前に1回だけ起きる。仕分けをせず、その場で見て待てを押すイベント。いつもは「待って確かめる」ステージなので、ここだけ急がせて落差をつける。結果発表と同じ画面の中で続けて行う。

### 始まり方

- 館内放送のチャイムが鳴り、「タイムセール開始!」の大きな帯が出る
- 帯が出た瞬間に、ゲームをいったん止める(時計、動き、曲を止める)
- 止めている間に、オペレーターのカットインで説明する。セリフは2つに分ける。「人がどっと来る!全員殴っちゃう!」「くずれてたら宇宙人!市民にだけ待て!」
- 画面をタップすると始まる(「▼タップ」の印を出す)。読む前に始まらないように、自動では始めない
- 始めるタップは待てや行けのボタンに効かせない。止めてから0.3秒は、タップを受けつけない(一時停止のメニューと同じ)
- 一度ラッシュを見たことを、記録に残す(掛け合いを見たかと同じ形)。見たことがあれば、説明を1つにする(「タイムセール!市民にだけ待て!」)。止めてタップで始めるのは同じ

### 遊び方

- ヒーローはエスカレーターの前で立ち止まり、右から人が次々に走ってくる
- このエスカレーターは、ラッシュが終わるまでどの攻撃でも壊れない(波の最後の人を殴ったときの巻きぞえで壊れて、壊れたエスカレーターの前でラッシュが始まらないように)。光のパンチの拳は、壊れないエスカレーターに当たって止まる
- 8人のうち宇宙人は3人か4人(半々で決める)。見た目は仕分けと同じ4種類
- 最初の2人は、市民1人と宇宙人1人にする(どちらが先かはランダム)。始めてすぐに、くずれる人とくずれない人の両方を見せるため
- 人の走る速さと間隔

| 項目 | 値 |
|---|---|
| 人の走る速さ | 1秒に60ドット |
| 次の人が来るまで | 最初の2人は2秒、そのあとは1.7秒 |
| 待てのマークが出る | 人がヒーローの48ドット手前に来たとき |
| マークが出ている長さ | 約1秒(殴る瞬間に消える) |
| 全体の長さ | 8人で約16秒(最後の人が出る12.5秒、マークまで走る2.2秒、マーク1秒、終わるまで0.6秒で16.3秒) |

- マークは一度に1人だけに出る(間隔の1.7秒を、マークの1秒と急ブレーキのポーズの0.6秒を足した長さより長くしてある。殴る動きは急ブレーキより短い)
- 最後の人を殴るか通してから0.6秒で終わる。のびた人が消えるのと、通した人が去るのは、終わりの一言と重なってよい
- マークの間も動きはゆっくりにしない(急がせるため)
- ちらりとヒーローの決めつけは出さない(全員にマークが出るので、ちらりを出すと正体がすぐ分かるため)。ヒーローは全員に同じ一言(「セール荒らしめ!」)を言う
- セールに夢中の宇宙人は人間のふりを忘れ、0.3秒に1回くずれる。町の画面では絵が小さいので、くずれのたびに体全体に黄緑のノイズを重ねて見せる
- 市民は、それぞれのぎこちなさ(ふらつく、船をこぐなど)を出す
- 技は光のパンチだけにする。巻きぞえは出さず、物も壊れない(被害額は増えない)
- 市民を殴ったときは、ヒーローが「あれ?」と言って次へ行く短い反応だけにする。「言いはる」「…ワルにしたの、私だけど」「やっちまったー」は出さない
- 待てで止めた宇宙人に、オペレーターの「あ、ワルだったかも…」は出さない
- 行けは使わない。ラッシュの間は行けのボタンを暗くする
- 早送りはラッシュの間は切り、終わったら前の状態に戻す
- ゆっくりモードでは、次の人が来るまでの間隔を1.5倍にする(SPECの一時停止と設定の見出しにも書き足す)
- ラッシュも一時停止できる。画面を離れたときも止まる
- UFOは来ない

### 数え方

ラッシュの数は、ほかの数字(悪党を倒した、市民のけが、逃がした、仕分け正解)に入れない。「全員倒した」のもとになる悪党の数にも入れない。ラッシュだけの数として数える。

| 押し方 | 本当は宇宙人 | 本当は市民 |
|---|---|---|
| 待てを押さない | セールで倒した | セールで殴った |
| 待てを押す | セールで逃がした | セールで守った |

- 「待ての達人」には入れない
- 波2の答え合わせの最後に、1行だけまとめを出す。例:「セール:撃破3/4・守った2/4」
- 結果画面の数字の窓にも、同じまとめを小さく出す
- ラッシュで市民を殴った場面は、「いちばんひどい場面」の候補に入れる(市民を殴った瞬間と同じ段)

## ボス:宇宙人の親玉

- 波3の仕分けの中に、市民に化けた親玉が1人いる。化けた姿は、寝不足の店員、買い物客のおじさん、着ぐるみのバイトの3つから選ぶ
- 化けた姿は市民とほぼ同じだが、どこか1か所だけおかしい(名札が逆さ、耳がとがっている、着ぐるみから触角がのぞく)
- 親玉は、化けた姿の市民と同じぎこちない動きをするが、くずれは出ない(ボスはふりが上手)。見た目のおかしい所で見分ける
- 正体を現すところはステージ1と同じ流れ

### ボス戦

- 連打で戦うのはステージ1と同じ。体力は連打40回分、最長15秒、負けはない
- 体力が半分を切ると、親玉が天井を破って母艦を呼び、乗りこむ
  - 連打すると、ヒーローが母艦ごと殴る(連打はそのまま体力を減らす)
  - 手が止まっている間は、母艦が光線で床を焼く。1秒ごとに被害額¥150万
  - 倒したときは、母艦が噴水に落ちて爆発し、親玉が目を回して出てくる。噴水の¥150万を被害額に足す
- 連打で揺れるのは、殴られている親玉(乗りこんだあとは母艦)だけ。画面の揺れはステージ1と同じくひかえめにする
- 親玉を市民に仕分けていた場合は、正体を現したあと母艦の光線でモールを焼く(被害額に¥2,000万を足す)
- 母艦の動きは、ステージ2の女ボスの車の作りを使って作る

## 共有

- 共有カードの「いちばんひどい場面」の右上に出すステージ名は「モール」にする(「ショッピングモール」では幅が足りない)。ステージの定義に、カード用の短い名前を持たせる
- 大きな物が壊れた場面の説明の文は「モールがこわれた!」
- 買い物客が連れ去られた場面も「いちばんひどい場面」の候補に入れる。順番は「市民を殴った瞬間」のすぐあと、「車や自販機が壊れた瞬間」の前。説明の文は「市民がさらわれた!」
- 写真は、買い物客が光の中でいちばん高く浮いたところを撮る(さらわれたときだけ使う)。UFOが来ている間はカメラを少し右へ寄せ、UFOがカードの上の2つの札の間に入るようにする。説明の字は、UFOと買い物客に重ならないように左下に出す
- 写真を撮るコマでは、頭の上の札(「市民」「ワル」)と画面の端の点滅を写さない(説明の字と重ならないように。どの場面の写真も同じ)
- 被害額のたとえはモールの物にする(¥50万未満はガチャガチャ、¥2億未満は噴水、それより上はエスカレーター)
- 称号の数は全部のステージを合わせて数える(例:称号5/17)

## 作るときのメモ

- 今のコードは「地下駐車場かどうか」で分けている所が多い。ステージの定義に、そのステージの仕組み(なし、ギャング、UFO)と、タイムセールラッシュがあるかどうかを持たせる形に直してから、ステージ3を足す
- 物の種類ごとの表(被害額、壊れやすさ、たとえ)に、モールの物を全部入れる
- 称号の順番の番号と、称号の数を決め打ちしているテストを直す
- 統計に、ラッシュの数(宇宙人の数、倒した数、市民の数、守った数)と、UFOを落とした数、さらわれた数を足す

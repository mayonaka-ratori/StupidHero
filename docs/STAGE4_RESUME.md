1. `docs/BOARD.md`を読み、T35とT36を`doing`にもどす
2. `npm ci`のあと、`npx vite --port 5173 --strictPort`を後ろで動かす
3. 上の「NGが出たもの」を1つずつ動かし直す。ほかの確かめと同時に動かさない(同時に動かすと、時間に左右されるNGが出る)。まず`node tools/boss_test.mjs`の`tower`(スクリプトの使い方の行を見る)
4. 本当の不具合なら直してテストを足す。スクリプトのまちがいならスクリプトを直す

- サブエージェントの作業場所(worktree)では、開発用のサーバーがフォントを読めずに403になることがある。作業場所に`node_modules`のリンクを置き、Viteの設定の`server.fs.allow`に元のフォルダを足すと動く(作業用フォルダに置いた設定を`--config`で渡す。リポジトリには入れない)
